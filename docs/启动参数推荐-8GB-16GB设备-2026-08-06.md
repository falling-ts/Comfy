# 启动参数推荐 · 8GB 显存 / 16GB 内存设备(2026-08-06)

> 针对本机实测配置(NVIDIA RTX 4060 8GB + 16GB RAM)与已下载模型负载,给出最佳启动参数及依据。所有参数均经 `ComfyUI/comfy/cli_args.py` 源码核实。

## 一、设备与模型负载

### 硬件
| 项 | 值 |
|---|---|
| GPU | NVIDIA RTX 4060,8GB 显存 |
| 内存 | 16GB |
| 系统 | Windows 11 |
| torch | 2.13.0+cu130(⚠️ 该构建 `F.scaled_dot_product_attention` 有 bug,见下) |

### 已下载模型(远超 8GB/16GB,全部依赖动态卸载)
| 模型 | 大小 | 用途 |
|---|---|---|
| qwen_image_edit_2511_fp8mixed | 19GB | 图片指令编辑 |
| minimax_h3_fl2va / ref2va(int8) | 各 20GB | 视频生成 |
| qwen_image_2512_fp8 | 20GB | 文生图 |
| qwen3vl_32b_minimax_h3_nvfp4 | 15GB | H3 文本编码器 |
| flux-2-klein-9b-fp8 | 8.8GB | 图生图/重绘 |
| qwen_2.5_vl_7b / qwen_3_8b | 各 ~8GB | 文本编码器 |
| stable_audio_3 | 8.6GB | 音频 |

> **关键约束**:单个模型文件就超过 16GB RAM → 权重**无法驻留内存**,必须从磁盘按需加载。8GB 显存 → 任何模型都需动态卸载。

## 二、推荐启动命令(已在 `start-comfyui.cmd` 生效)

```
python.exe main.py --enable-manager --disable-pinned-memory --fast-disk
```

| 参数 | 必要性 | 依据 |
|---|---|---|
| `--fast-disk` | ⭐ 核心 | 20-39GB 模型在 16GB RAM 下只能走**磁盘动态加载/卸载**(`model_management.py` 中磁盘替代 RAM 驻留)。NVME 上最快。不加则大模型加载会爆内存 |
| `--disable-pinned-memory` | ✅ | 修复 0.30.x pinned-memory 加载回归;16GB RAM 也 pin 不下大模型 |
| `--enable-manager` | ✅ | ComfyUI-Manager 插件管理 |

## 三、按需增强参数(遇到问题时加)

| 场景 | 参数 | 说明 |
|---|---|---|
| H3 推理时桌面卡死/系统崩溃 | `--reserve-vram 0.5` | 给桌面/浏览器预留 0.5GB(Windows 共享显存)。代价:牺牲 H3 少量可用显存,仅按需加 |
| 内存碎片/峰值 OOM 不稳 | `--vram-headroom 0.3` | DynamicVRAM 保持 0.3GB 完全空闲。代价:同样牺牲少量显存 |

> 8GB 卡跑 H3 本已极限,**不建议默认**加上述两项;先用基础配置,遇到具体问题再按需启用。

## 四、明确「不要加」的参数

| 参数 | 为什么禁用 |
|---|---|
| `--highvram` / `--gpu-only` / `--high-ram` | 让模型驻留 VRAM/RAM → 8GB/16GB 直接 **OOM 崩溃** |
| `--use-sage-attention` | 全局替换所有模型 attention(含文生图),曾有黑图史。sage 应通过工作流节点(KJNodes `Patch Sage Attention KJ`)定向启用 |
| `--use-pytorch-cross-attention` | 内部调 `F.scaled_dot_product_attention` → **torch 2.13.0 该函数已损坏**(见附注) |
| `--fp16-vae` | 源码标注 "might cause black images" |
| `--fast` | 实验性质量损失优化,可能崩溃 |
| `--lowvram` / `--novram` | 动态 VRAM 时代已无意义 |
| `--force-fp16` / `--force-fp32` | 全局精度,质量/性能双重受损 |
| `--enable-triton-backend` | 仅 ROCm/AMD 路径用;NVIDIA 用 comfy-kitchen CUDA 后端(已激活) |
| `--deterministic` | 大幅变慢,出图可复现非必需 |

## 五、重要提醒(非启动参数)

1. **虚拟内存(pagefile)**:16GB RAM 跑 20GB+ 模型,务必确认 Windows 虚拟内存已开启且足够大(系统托管或 ≥32GB),否则磁盘分页会引发卡顿。
2. **torch 2.13 SDPA 损坏**:`F.scaled_dot_product_attention` 在该构建下输出错误(与 fp64 权威 cosine≈0.01,含 fp64/MATH backend)。ComfyUI 默认 `attention_sub_quad` 不受影响;受影响的是 `--use-pytorch-cross-attention` 及直接调 SDPA 的第三方节点。
3. **sageattn 数值正确**:2.2.0.post6 所有 kernel 与 fp64 权威一致(cosine≥0.9993),可放心通过工作流节点用于文生图/H3。
