### 1.3 能力结论

- **要「具身/机器人世界模型」的榜：BLM（同济）是开源第一**，而且是唯一同时拿下视频质量与 Policy Evaluator 两个赛道开源第一的项目。
- **要「单图/单目视频 → 可自由换机位 + 4D」的榜：UniWorld-View 第一**，且是 Apache-2.0；但官方要 ≥60GB。
- **腾讯系在「显式 3D 世界」上仍是开源主力**（Voyager 3D 赛道第一梯队、HY-World 2.0 生态最大），但都是 24–80GB 量级。
- **两个榜单都还没收录** HY-World 2.0 / Matrix-3D / Lyra / Waypoint —— 榜单空位 ≠ 能力不行，只是没提交。

## 4. 口径与陷阱（读榜必看）

1. **自评 ≠ 官方评**：WorldScore 上 2025-03-30 之后的绝大多数行是团队自报（`Sampled by`/`Evaluated by` 都是自己）。UniWorld-View 的 85.53、Voyager 的 77.62、FantasyWorld 的 78.55 **都属自评**。只有 2025-03-30 那一批是 WorldScore 官方评测。
2. **榜单空位 ≠ 能力不行**：HY-World 2.0、Matrix-3D、Lyra、Waypoint、Oasis 均未出现在两个榜单里（未提交）。
3. **HF `downloads` 是近 30 天口径**，会被 CI/Agent 反复拉取放大（Cosmos3-Nano 12.6 万次下载 ≈ 12.6 万次 `snapshot_download`，不代表 12.6 万个用户）；★ 更能反映「人类关注度」。
4. **门控仓库无法直接下载**：`Etched/oasis-500m`、`nvidia/Cosmos-Predict2.5-2B`、`Skywork/Matrix-3D`、`facebook/VGGT-Omega`、`facebook/VGGT-1B-Commercial` 均需登录/同意条款。
5. **许可雷区**：`nvidia/Lyra-2.0` 代码 Apache-2.0 但**权重是非商用**（NVIDIA Internal Scientific R&D Model License）；混元系为社区许可（可商用，排除 EU/UK/韩，MAU>100 万需申请）；`lingbot-world` / `World Dreamer` / `EvoPhys-World` 等许可未取证。
