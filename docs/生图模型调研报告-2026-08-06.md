## 三、生图模型档案(最新 → 最老)

### 1. Krea 2(2026-06 开源)
- **参数/架构**:12.9B 单流 DiT(28 层 × 6144 宽,GQA + 门控 sigmoid 注意力,SwiGLU,3D 轴向 RoPE);RAW 与 Turbo 双版本,附 9 款官方 LoRA
- **训练数据特点**:预训练分 256px / 512px / 1024px 三阶段;数据严格过滤(去重、去 VLM 无法描述、去低分辨率复杂样本、**完全不用 AI 生成图**);训练数据含"数十亿张真实人类图像"
- **生图风格**:美学优先、风格辨识度高,偏写实商业摄影;艺术风格复刻精度中等
- **分辨率**:训练至 1024px 级;官方 ComfyUI 模板常规 1024×1024,可自定义 16 倍数
- **编辑能力**:以文生图为主,官方 LoRA 覆盖 9 类风格;编辑属基础变体级

### 2. Ideogram 4(2026-06 开源)
- **参数/架构**:9.3B,34 层 DiT,文本/图像 token 每层共享投影
- **训练数据特点**:面向设计场景(海报/排版/Logo),文字与图像联合建模
- **生图风格**:设计向,文字排版、多语言文字渲染开源最强(超过 Qwen-Image 20B、FLUX.2 32B、混元 80B);艺术风格多样
- **分辨率**:原生 2K 输出;支持 bounding box 精确控制物体/文字位置、调色板控制
- **编辑能力**:以文生图+排版为主,可作文字海报专用;商业许可

### 3. HiDream-O1-Image(2026-04 开源,5 月 Dev 版)
- **参数/架构**:8B 蒸馏版(闭源版千亿参数);**UiT 像素级统一 Transformer,无 VAE、无外部文本编码器**,原生编解码像素
- **训练数据特点**:原生全模态架构,像素级联合训练;开源版为蒸馏模型
- **生图风格**:真实感、细节与语义遵循强;GenEval / DPG / HPSv3 超越 7 倍体量模型(如 56B FLUX.2)
- **分辨率**:原生最高 **2048×2048(2K)**
- **编辑能力**:原生支持文生图、图像编辑、主体个性化;因无 VAE,ComfyUI 需专用自定义节点

### 4. ERNIE-Image(2026-04 开源,百度,Apache 2.0)
- **参数/架构**:8B 单流 DiT + 轻量 Prompt Enhancer;有 Turbo 蒸馏版
- **训练数据特点**:面向中文指令遵循、文字渲染、海报式版式与结构化构图(SuperCLUE 图文一致性与汉字生成国内第一)
- **生图风格**:真实感(1024×1024 下表现佳)、版式/文字/海报强,中文理解强
- **分辨率(官方支持)**:1024×1024、848×1264、1264×848、768×1376、896×1200、1376×768、1200×896
- **部署**:24GB 消费级显卡可跑;官方 ComfyUI Workflow + GGUF 量化
- **编辑能力**:以文生图为主;指令遵循强(适合"按需求改版式/加文字")

### 5. FLUX.2 Klein(2026-01 发布,BFL)
- **参数/架构**:4B / 9B 蒸馏修正流模型(9B 为质量最佳点)
- **训练数据特点**:FLUX.2 家族训练数据,蒸馏至 4-8 步;优化真实感与亚秒级生成
- **生图风格**:真实感优先,兼修文字/UI 素材;编辑与生成统一
- **分辨率**:基准 1024×1024(DeepWiki 官方示例),可自定义 16 倍数
- **编辑能力**:**亚秒级生成+编辑(多图)**,消费级 GPU 可跑;常用于分块重绘/一致性

### 6. Qwen-Image-2512 / Qwen-Image-Edit 2511(2025-12 发布,阿里)
- **参数/架构**:20B MMDiT;2512 文生图,2511 指令式编辑;Lightning 4/8 步蒸馏 LoRA
- **训练数据特点**:高质量图文对,强化中文、复杂文字渲染、自动布局;目标"零 AI 感"
- **生图风格**:人物真实感、自然细节、中文与文字渲染强;国漫/CG 风格兼容;开源盲测(AI Arena)榜首
- **分辨率(文生图)**:官方 7 种宽高比(1:1/16:9 等)+ 自定义(16 整除);fal 接口目标约 1.6MP;第三方实验可达更高
- **编辑能力(Qwen-Image-Edit 2511)**:指令式编辑(文字编辑/物体增减/风格变换/局部重绘);**官方输出尺寸**:1024×1024、1024×1280、1280×1024、1280×1280、1280×1536、1536×1080;第三方节点可编辑到 **16MP**;多图参考、LoRA 风格化、Lightning 4 步加速

### 7. Z-Image / Z-Image-Turbo(2025 年末开源,阿里通义)
- **参数/架构**:多模态联合预训练,DiT 系;Turbo 蒸馏为 4-8 步、无 CFG
- **训练数据特点**:强调中文语义与指令理解、宽高比自适应
- **生图风格**:国风/真实/插画多面手,中文提示词友好
- **分辨率**:自动分辨率计算;宽屏示例 1280×720、1920×1080、2560×1440(16:9 / 9:16)
- **编辑能力**:以文生图为主;社区 LoRA 丰富(瑶光/真实幻想等)

### 8. FLUX.1 dev / Redux / Kontext(2024-08,BFL)
- **参数/架构**:12B 修正流(dev);Redux 为变体适配器;Kontext 为上下文图像(长图/多图)
- **训练数据特点**:高质量授权数据,强调提示词遵循与写实
- **生图风格**:写实摄影/插画/文字全能;经典工作流基准
- **分辨率**:1024×1024 基准,可到 2K
- **编辑能力**:Redux 做风格迁移/图生图变体;Kontext 做多图上下文

### 9. Seedream 4.5 / 5.0(字节,闭源 API)
- **参数/架构**:未公开,火山引擎/即梦/豆包提供
- **训练数据特点**:字节级海量数据,多图一致性、美学控制、空间逻辑专项强化
- **生图风格**:艺术质量高,中国传统美学/数字艺术/创意插画;中文本土审美词理解强
- **分辨率**:原生 **2K**(即梦 4.5),Seedream 4.5 支持 **4K** 输出
- **编辑能力**:文生图、图生图、**多图参考编辑**;闭源,ComfyUI 不可本地跑

### 10. 混元 Image 3.0(腾讯,80B MoE)
- **参数/架构**:80B MoE,参数量巨大;有开源版本(HunyuanImage)
- **训练数据特点**:腾讯系数据,中文优化
- **生图风格**:中文指令、写实与 CG 兼顾;榜单上游但生态一般
- **分辨率**:1024 级
- **编辑能力**:基础文生图;开源版 ComfyUI 支持有限

### 11. SD 3.5 / SDXL(Stability,2024-10 / 2023-07)
- **参数/架构**:SD3.5 MMDiT + 修正流;SDXL 双文本编码器(OpenCLIP + CLIP)
- **训练数据特点**:SDXL 1024×1024 数据级;SD3.5 强化提示词遵循
- **生图风格**:老牌生态,Lora/ControlNet 最全;写实为主
- **分辨率**:1024 级
- **编辑能力**:靠 ControlNet/IP-Adapter 等外围,模型本身为文生图

### 12. Kolors(可图,快手,2024-07 开源)
- **参数/架构**:SDXL 系变体,数十亿图文对
- **训练数据特点**:中英双语,支持图中生成中文
- **生图风格**:中文语义、写实与 CG;B 站教程存量多
- **分辨率**:1024×1024 基准
- **编辑能力**:基础文生图

## 四、图片修改(编辑)模型专项:分辨率样式与修改程度

| 模型 | 支持分辨率样式 | 修改程度/能力 |
|---|---|---|
| Qwen-Image-Edit 2511 | 官方 1024×1024 / 1024×1280 / 1280×1024 / 1280×1280 / 1280×1536 / 1536×1080;第三方 16MP | 指令式编辑:改文字、增减物体、换风格、局部重绘;保留主体细节;多图参考;4 步 Lightning |
| FLUX.2 Klein | 1024 基准,自定义 16 倍数 | 生成+编辑统一,亚秒级;适合分块重绘/细节增强 |
| HiDream-O1-Image | 最高 2048×2048(2K) | 图像编辑 + 主体个性化 + 文生图,像素级原生 |
| Seedream 4.5(闭源) | 2K / 4K | 多图参考编辑、多图一致性、空间逻辑 |
| FLUX.1 Redux | 1024 基准 | 风格迁移、图像变体 |
| ERNIE-Image | 7 种官方尺寸(见上) | 指令遵循强,适合版式/文字修改;Turbo 蒸馏加速 |

> 说明:ComfyUI 本地可用的编辑主力是 **Qwen-Image-Edit 2511**;要"改分辨率样式"时,官方 6 种尺寸是基准,第三方节点(Eric_Qwen_Edit_Experiments 等)可把编辑分辨率提升到 16MP;修改程度通过提示词指令控制(改文字/增删物体/风格迁移),并可用 denoise 控制幅度。

## 五、生图模型流行度排序(综合 RunningHub + B 站 + 全网)

1. **Qwen-Image-2512 / Edit 2511**(开源,综合第一:RunningHub 使用量最大、B 站提及最多、AI Arena 开源榜首、中文最强)
2. **FLUX 系(1 / 2-Klein / Redux / Kontext)**(开源,海外主流,国内热度第二,编辑生成一体)
3. **即梦 / Seedream 4.5-5.0**(闭源,国内普通用户最火,2K/4K,多图编辑)
4. **Z-Image(Turbo)**(开源,低配友好、宽屏分辨率自适应)
5. **ERNIE-Image**(开源,SuperCLUE 中文第一、轻量 8B、文字/版式强)
6. **HiDream-O1-Image**(开源,榜单第一新贵、2K 原生、无 VAE 新架构)
7. **Krea 2**(开源,美学优先、商业摄影风)
8. **Ideogram 4**(开源,文字/海报渲染最强)
9. **SD3.5 / SDXL**(老牌生态,Lora/ControlNet 最全)
10. **Kolors**(快手,中文向,教程存量多但生态老化)
11. **混元 Image 3.0**(腾讯,80B,生态一般)

## 六、选型建议(针对本工作区)

- **文生图主链**:维持 Qwen-Image-2512(最火开源、中文强、与现有工作流/表格体系完全兼容)
- **图生图/修图**:Qwen-Image-Edit 2511(6 种官方尺寸,16MP 上限,指令式编辑)
- **追求榜单第一/2K 原生**:HiDream-O1(需专用节点,生态较新)
- **轻量/低配**:ERNIE-Image(8B,24GB)或 Z-Image-Turbo(4-8 步)
- **文字/海报/排版**:Ideogram 4;美学向:Krea 2
- **分块重绘/细节增强**:FLUX.2 Klein(已在用)
- **国内下载**:魔搭 ModelScope 或 hf-mirror;闭源(即梦/Seedream)仅云端
