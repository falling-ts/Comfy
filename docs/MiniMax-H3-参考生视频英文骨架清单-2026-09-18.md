# MiniMax H3 参考生视频（Ref2VA）英文骨架标识符清单

> 整理日期：2026-09-18
> 适用：`0044-参考视频`（Ref2VA 全参考模式）、`0032-参考场景`（Ref2VA，主体换场景）
> 来源：官方 `h3-prompt-writing` 技能 `references/ref-en.txt` 与 `base-en.txt`、官方 `h3/MiniMax-H3/skills/h3-prompt-writing/SKILL.md`、本地技能 `h3-prompt-writing` / `stories-resource-tables` / `stories-video-prompts` / `stories-scene-video`、ComfyUI 源码 `comfy/text_encoders/minimax.py`
>
> **本文只收录「必须写英文、且不能改写」的骨架标识符**，不收录正文英文写作风格建议。

---

## 0. 总原则

H3 的提示词里有两类文字，规则完全不同：

| 类别 | 语言 | 能否改写 |
| :--- | :--- | :--- |
| **骨架标识符**（字段名、标签、枚举值、结构标记、固定短语、运镜术语） | **一律英文** | **严禁改写、翻译、缩写、改空格、改标点** |
| **正文白话**（画面、运镜、光影、动作、声音的描述句） | **英文** | 可自由组织，但须英文 |

**正文为什么也要英文**：H3-Encoder 取 Qwen3-VL-32B 第 50 层隐状态，生成主干在英文条件上训练，中文条件落在分布外；本机编码器是 4-bit 量化版，中文词义错乱率约为英文的 1.7 倍。本机 11 组受控实测显示中文正文会稳定把参考脸拍熟 2~3 岁（详见 `MiniMax-H3-中英提示词差异调研-2026-09-18.md`）。

**只有两处例外保留原语言**：
1. `<d>` 内的对白 / 歌词 —— 逐字保留、不翻译
2. 画面内实际可见的文字（招牌 / 字幕 / 标签）—— 逐字保留，用**英文双引号**包住，如 `a sign reading "营业中"`

## 1. 真 Special Token（tokenizer 硬编码，7 个）

这些不是普通文本，而是基础词表（0..151668）之外的**扩展 special token**。译成 `<对话>` 只会被切成两个普通 token，指令直接失效。

| Token | ID | 含义 | 在 Ref2VA 里的用法 |
| :--- | :--- | :--- | :--- |
| `<d>` | 151669 | 对白 / 歌词块**开始** | 说话人身份、音色、语气写在 `<d>` **之外**；`<d>` 内只放「英文语言名 + 用户原始说话内容」 |
| `</d>` | 151670 | 对白 / 歌词块**结束** | 完整陈述句 / 疑问句 / 感叹句在 `</d>` 前分别以 `.` `?` `!` 收尾 |
| `<\|cutoff\|>` | 151671 | 语音被视频结尾**截断** | 话没说完就到片尾时标记 |
| `<\|lyrics_start\|>` | 151672 | 歌词块开始 | 唱歌内容，与 `<d>` 配合 |
| `<\|lyrics_end\|>` | 151673 | 歌词块结束 | — |
| `<\|caption_start\|>` | 151674 | 屏幕文字 / 字幕块开始 | — |
| `<\|caption_end\|>` | 151675 | 屏幕文字 / 字幕块结束 | — |

> 注：上表第三行写的是 `<|cutoff|>`（竖线包裹），为避免与本文件表格分隔符冲突加了转义，实际写进提示词时**不带反斜杠**。

**编码器内部使用、不手写**：`VISION_START = 151652`、`VISION_END = 151653`（视觉块包裹），空输入占位 `151643`（pad）。

## 2. 编码器自动注入的标签（**不手写**，别写进提示词）

`comfy/text_encoders/minimax.py` 在拼接参考资产时自己写入这些文本，我们只在提示词**正文里用无冒号的裸标签引用它们**。

| 注入文本 | 出现位置 | 说明 |
| :--- | :--- | :--- |
| `<Picture i>: ` | 每张参考图前 | **带冒号 + 空格**，由编码器累加生成 |
| `<Video k>: ` | 每段参考视频前 | 同上 |
| `<Audio j>: ` | 每段参考音频前 | 同上（音频不进 Qwen 视觉侧） |
| `<X.X seconds>` | 视频每 2 帧时间块前 | 例 `<0.0 seconds>`、`<1.5 seconds>`，按参考视频抽帧时间戳生成 |

**易错点**：我们手写引用时写 `<Picture 1>`（**无冒号**）；带冒号的 `<Picture 1>: ` 是编码器输出，写进提示词属于重复。

## 3. 四类参考标签（`<>` 包裹，必须手写）

### 3.1 标签总表

| 标签 | 含义 | 用于什么 | 是否独立成定义行 |
| :--- | :--- | :--- | :--- |
| `<Subject N>` | 从参考资产中**抽象出的、可复用/可修改的可见内容** | 人物、动物、器物、场景、环境、服装、道具、界面、特效、风格、动作、表情、姿势 | ✅ 独立成行 |
| `<Picture N>` | 用作**具体目标帧**或**分镜规划锚点**的参考图 | 首帧、关键帧、尾帧、编辑关键帧、构图锚点、故事板 | ✅ 仅当充当帧锚点时独立成行；**只用来定义角色/场景/服装/风格时，写进对应 `<Subject N>` 定义里，不另起一行** |
| `<Video N>` | 提供**剪辑源、续写起点或整片时间结构**的参考视频 | 剪辑原片、从原片结尾续写、参考原片的运镜/剪辑点/节奏/时间结构 | ✅ 独立成行 |
| `<Audio N>` | 被**复制或引用**的音频信号 | 复制全部/部分音频、参考 BGM 风格、参考说话人音色与表达、复用原音频的对白/歌词/音效、参考节拍/节奏/音频连续性 | ✅ 独立成行 |

### 3.2 写法硬规则

- **整枚标签连同数字与空格一并照抄**：写 `<Picture 1>`，**不是** `<Picture1>`、`<picture 1>`、`<图片 1>`。
- **N 是"非空参考"的连续排位，不是数据表列号**：编码器对每个非空参考逐张累加编号，空槽被 `if img is None: continue` 跳过。参考必须**从第 1 列起连续填写**，中间留空会让提示词编号与实际参考错位。
- **一张图内多个元素归属哪个 Subject 必须用文字点名**（必要时用方位词），模型不会自动按画面左右分配。
- **标签一旦分配，含义跨段不变**：在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、两个声音段里含义必须一致；`summary` **不得引入新标签**。
- **`<Picture N>` 的两种用法互斥**：作具体帧锚点才独立成条；仅定义角色/场景/服装/风格时须并入 `<Subject N>`。
- **`<Video N>` 与 `<Audio N>` 各自独立编号**：同一段参考视频可以同时是 `<Video 1>` 和 `<Audio 2>`，索引不编码配对关系。普通参考视频**不因为文件带声音就自动产生 `<Audio N>`**。
- **`<Audio N>` 绑定说话人时复用全局说话人 ID**：写 `<Subject N> (Sx)`；说话人不属于任何已定义 Subject 时，用稳定的声音描述 + `(Sx)`。该 ID 来自目标视频的全局说话人顺序，**音频定义里不得自行编号或重排**。

### 3.3 Subject 三层绑定机制

1. **`subject_definitions` 登记**：文字描述内容并编号，建立「`<Subject N>` = 某内容」的映射
2. **`detailed_description` 首次出现落地**：写「标签 + 完整特征描述 + 画面位置 + 当前动作」，这是模型建立编号与画面对应关系的关键；只写编号不写特征会让绑定变弱
3. **`retention_analysis` 追踪**：逐项说明保留 / 转移 / 复制 / 引用情况

## 4. 六部分字段名（英文单词 + 英文冒号，顺序固定）

| 顺序 | 字段名（**含英文冒号**） | 含义 |
| :--- | :--- | :--- |
| 1 | `subject_definitions:` | 定义被参考内容及其参考标签 |
| 2 | `summary:` | 概括任务类型、目标视频与主要参考关系 |
| 3 | `retention_analysis:` | 描述被参考内容如何保留、转移或复用 |
| 4 | `detailed_description:` | 按播放顺序描述画面、动作、镜头、声音与对白 |
| 5 | `overall_soundscape:` | 概括全片环境音与物理动作声 |
| 6 | `non_diegetic_music:` | 描述角色听不到、仅观众能听到的背景音乐 |

**对照：基础模式（T2VA / I2VA / FL2VA / L2VA）只有三个核心字段**，顺序为：

| 顺序 | 字段名 |
| :--- | :--- |
| 1 | `integrated_multimodal_description:` |
| 2 | `overall_soundscape:` |
| 3 | `non_diegetic_music:` |

**Ref2VA 与基础模式的关键差异**：主字段名换成 `detailed_description:` 且拆成六段；风格句写在 `[Shot 1]` **之前**（基础模式写在 `[Shot 1]` 之后）。

## 5. 任务类型前缀（方括号，写在 `summary:` 首句开头）

| 前缀 | 何时使用 |
| :--- | :--- |
| `[reference generation]` | 图/视频/音频只提供角色、场景、风格、动作、运镜、分镜等生成指导，**不充当具体帧、也不是被剪辑或续写的源片** |
| `[keyframe completion]` | 某张图充当目标视频的首帧、关键帧、尾帧、编辑关键帧等**具体帧锚点** |
| `[video editing]` | 直接修改一段已存在的源视频（编辑图片或在静帧之间生成**不属于**此类） |
| `[video continuation]` | 新内容从已存在的源视频**继续、延长、接续或转场** |
| `[audio reuse]` | 同一段音频信号被全部或部分**复用** |
| `[audio reference]` | 音频不被直接复制，只参考其音乐风格、音色、对白/歌词内容、音效质感、节拍或连续性 |

**组合规则**：多关系用 ` + ` 连接，**同一类型不得重复**。例：`[reference generation + audio reference]`、`[video continuation + keyframe completion]`、`[video editing + audio reuse]`。

**只是"有视频/有音频"不自动产生对应任务类型**：参考视频只提供运镜、剪辑或节奏时属 `reference generation`。

## 6. retention_analysis 关系标记（枚举值，必须英文 + 下划线）

### 6.1 可见内容（`<Subject N>` / `<Picture N>` / `<Video N>`）

| 标记 | 含义 |
| :--- | :--- |
| `fully_preserved` | 所定义的角色被完整保留 |
| `partially_preserved` | 仍在使用，但部分已定义特征被改变或只部分保留 |
| `attribute_transfer` | 参考特征被转移到另一个可识别的目标主体上 |
| `weak_reference` | 仅保留风格、类别、构图或氛围上的宽泛相似 |

### 6.2 音频（`<Audio N>`）

| 标记 | 含义 |
| :--- | :--- |
| `fully_copy` | 完整源音频作为目标视频的完整最终音轨 |
| `partially_copy` | 只复制部分时间线或部分音层，或复制后新增/删除/替换了其它声音 |
| `reference` | 不直接复制信号，只参考音色、节奏、音乐风格、对白内容或声音质感 |
| `weak_reference` | 仅保留类别或氛围上的宽泛相似 |

**书写规则**：关系标记只能在 `subject_definitions` 已为该标签定义的角色范围内选择；**目标视频里新增的动作、背景、剧情事件不算参考保真度损失**。

**`retention_analysis` 里严禁写 `(Sx)`** —— 说话人编号只在 `detailed_description` 里出现。

### 6.3 四种条目的标准行式

```text
<Subject 1> (appears in [Shot 1], [Shot 3]): fully_preserved - ...
<Picture 2> ([Shot 1] first frame): fully_preserved - ...
<Video 1> (cut and pacing structure): weak_reference - ...
<Audio 1>: fully_copy - <Audio 1> is reused 1:1 as the target video's complete final audio track.
```

## 7. 镜头与说话者结构标记

| 标记 | 含义 | 写法 |
| :--- | :--- | :--- |
| `[Shot 1]` | 开场镜头 | **不带时间戳** |
| `[Shot N]` | 后续镜头 | N 为递增序号 |
| `At MM:SS.mmm,` | 切点时间 | 例 `[Shot 2] At 00:03.500, the camera cuts to...`；**严格递增**且须落在视频时长内 |
| `(S1)` `(S2)` | 说话人 / 演唱者 / 画外人声的稳定 ID | 写在 `<d>` **之外**；跨镜头保持不变；**从不发声的角色不给 ID** |
| `(S1,S2)` | 多个已编号说话人**同时**说话或演唱 | 复合 ID |
| `(S1)` + `off-screen` | 同一角色在画外发声 | 保持同一写法并标注画外 |
| `N/A` | 无内容 | 仅两处用：`non_diegetic_music` 无配乐时；`overall_soundscape` **仅当用户明确要求全片静音**时 |

**说话人 ID 分配规则**：按目标视频中**实际发声事件的先后顺序**分配一次，之后每个发声事件复用同一 ID；`subject_definitions` 里绑定到目标说话人的 `<Audio N>` 也复用同一 `(Sx)`，但**绝不自行分配新 ID**。

## 8. 对白、歌词与屏幕文字

| 内容 | 规则 |
| :--- | :--- |
| 语言名标签 | **英文语言名**，写在 `<d>` 内最前：`<d>[Chinese] 我们现在出发。</d>`、`<d>[English] ...</d>`、`<d>[Japanese] ...</d>`；**严禁写 `[中文]`** |
| `<d>` 内放什么 | **只有两样**：英文语言名标签 + 用户原始说话内容。说话人身份、音色、语气、语速、动作一律写在 `<d>` **之外** |
| `<d>` 内标点 | 只用 `,` `.` `?` `!`，且在 `</d>` 前收尾；**不写全角标点、不写省略号、不写重复波浪号、emoji、项目符号或装饰性标点**（见下方"标点口径分歧"） |
| 引用参考音频原词 | 保留原语言逐字；**听不清的片段写 `[unclear]`**，不得猜写或改写 |
| 只参考音色/节奏/情绪 | **不得**把参考音频里的原对白带进目标视频 |
| 歌词 | 同样写在 `<d>` 内，或配 `<\|lyrics_start\|>` / `<\|lyrics_end\|>` |
| 画面内可见文字 | 用**英文双引号**逐字包住、不翻译：`A red neon sign reading "营业中" glows above the doorway.` |
| 变调 / 语速 | 不能只靠 `<d>` 内容表达，须在 `<d>` 外写自然英文描述 |

## 9. 对白与画外的固定英文短语

| 场景 | 固定写法 |
| :--- | :--- |
| 画外音 / 内心独白（**嘴唇不动**） | 必须用**确切短语** `says in an off-screen voiceover`；**紧接每个画外音 `<d>` 块之后，必须写明对应画面角色的嘴唇保持闭合** |
| 对白跨切点 | 在两段连接处都写 `<scenetrans>`，并明说音频跨切点延续 |
| 语音被片尾截断 | 用 `<\|cutoff\|>` |
| 音频跨镜头连续性 | 可用 `continues seamlessly across the cut`、`continues uninterrupted into the next shot`、`carries over from the previous shot`、`remains audible across the transition` |
| 普通切镜头 | `the camera cuts to`、`the shot cuts to`、`the shot transitions to`、`the shot changes to`、`the shot switches to`；cross-dissolve / fade / wipe 仅在用户明确要求时用 |

**画外音标准句**：
```text
The man (S1) says in an off-screen voiceover: <d>[English] I still remember that road.</d> while his lips remain completely closed.
```

### 标点口径分歧（中文对白要特别注意）

官方 `ref-en.txt` 的原文是：`Standardize punctuation to the basic written marks needed to express the sentence, such as , . ? and ! ... End complete statements, questions, and exclamations with ., ?, or ! respectively before </d>.` —— 按字面，**中文对白也应以半角 `.` `?` `!` 收尾**。

但本库技能 `stories-resource-tables` 自己给的示例写作 `<d>[Chinese] 我们现在出发。</d>`，用的是全角 `。`，而同一段规则又写着"不写全角标点"，**两者自相矛盾**。

**处理建议**：以官方原文为准，中文对白写 `<d>[Chinese] 我们现在出发.</d>`（半角点收尾），句内仍可用中文逗号。这一条**尚缺本机对照实验**，属未验证项；若你更看重可读性而采用全角 `。`，风险仅限于"标点规范化不彻底"，**不影响 special token 生效与对白内容**。

### `<cutoff>` 与 `<|cutoff|>` 的官方文档 / 实现不一致（重要）

| 来源 | 写法 |
| :--- | :--- |
| 官方 `base-en.txt` / `ref-en.txt` / `base-cn.md` / `ref-cn.md`（四份一致） | `<cutoff>`（**无竖线**） |
| ComfyUI tokenizer（`comfy/text_encoders/minimax.py`） | `<\|cutoff\|>`，id **151671**；`MINIMAX_EXTRA_TOKENS` 里**没有**裸 `<cutoff>`，内核也没有做 `<cutoff>` → `<\|cutoff\|>` 的替换 |

**含义**：照官方文档写 `<cutoff>`，它会被切成普通 token，**拿不到 151671 这枚 special token**。要真正触发"语音被片尾截断"标记，应写 `<|cutoff|>`。
**保留意见**：官方四份文档一致写裸形式，也可能训练时该标记以裸文本出现、151671 另有触发路径；**本机未做对照实验，此条属未验证项**。

`<scenetrans>` 同理：官方文档使用它，但**源码里不存在对应的 special token**，它是纯提示词文本标签，靠模型语义理解，不会因写错而失效——但也别指望它有 special token 的强制力。

## 10. 镜头运动术语（英文，写进提示词时取英文）

| 维度 | 可用表达 | 说明 |
| :--- | :--- | :--- |
| 运动类型 | `Zoom In` / `Zoom Out` | 焦距变化，机身不动 |
| 运动类型 | `Push In` / `Pull Out` | 机身前进 / 后退 |
| 运动类型 | `Pan Left` / `Pan Right` | 机位不动，镜头水平摇 |
| 运动类型 | `Truck Left` / `Truck Right` | 机位水平平移 |
| 运动类型 | `Tilt Up` / `Tilt Down` | 机位不动，镜头垂直摇 |
| 运动类型 | `Pedestal Up` / `Pedestal Down` | 整机上升 / 下降 |
| 运动类型 | `Arc Shot` | 摄像机绕主体做弧线运动 |
| 运动类型 | `Tracking Shot` | 跟随移动主体 |
| 运动类型 | `Static Shot` | 机位与镜头均静止 |
| 运动类型 | `Shake Slightly` / `Shake Strongly` | 轻微 / 强烈抖动 |
| 运动类型 | `POV` | 主体视角 |
| 运动类型 | `Roll Clockwise` / `Roll Counterclockwise` | 绕镜头光轴滚转 |
| 幅度 | `with small amplitude` / `with large amplitude` | 中等幅度通常省略 |
| 速度 | `at slow speed` / `at fast speed` | 常速通常省略 |

**写法**：镜头运动须写成镜头内的**自然英文动作句**，不能把标签堆在句尾。

```text
The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.
```

## 11. 必须英文的其它固定值

| 项 | 值 |
| :--- | :--- |
| 风格词 | `Cinematic`、`live-action`、`2D-animated`、`3D CG`、`claymation`、`watercolor`、`vintage film` 等 |
| 时间格式 | `S.SS`（对齐指令，两位小数）；`MM:SS.mmm`（切点） |
| 保留字 | `<Picture N>` 里的 `N`、`(Sx)` 里的 `x` 均为阿拉伯数字，**不加前导零** |

**各类对齐指令的官方英文原句**（改模式时必须逐字套用）：

```text
# I2VA 首行
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

# FL2VA 首行
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.

# L2VA 首行
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.

# 关键帧锚定（写进 detailed_description 的镜头首句）
[Shot N] At S.SS, anchored to the frame established by <Picture N>.
```

## 12. 禁止写法对照表（写完必须自查）

| ❌ 错误 | ✅ 正确 | 后果 |
| :--- | :--- | :--- |
| `<图片 1>` | `<Picture 1>` | 标签失效，参考绑定丢失 |
| `<Picture1>` | `<Picture 1>` | 同上（空格是标签的一部分） |
| `<subject 1>` | `<Subject 1>` | 大小写敏感 |
| `[镜头 1]` | `[Shot 1]` | 镜头编号失效 |
| `[中文]` | `[Chinese]` | 语言标签失效 |
| `<对话>...</对话>` | `<d>...</d>` | special token 被切成普通 token，对白指令整体失效 |
| `fully-preserved` | `fully_preserved` | 枚举值不匹配 |
| `Fully Preserved` | `fully_preserved` | 同上 |
| `<Picture 1>: ` （写在提示词正文里） | `<Picture 1>` | 与编码器注入重复 |
| `[reference-generation]` | `[reference generation]` | 任务类型前缀不匹配 |
| retention 段里写 `(S1)` | 只在 `detailed_description` 写 `(S1)` | 违反规范 |
| `<d>` 内写说话人身份/语气 | 全写在 `<d>` 外 | `<d>` 内只允许语言标签 + 原始说话内容 |
| 中文正文描述画面 | 英文正文 | 落在条件分布外 + 量化损失，实测把参考脸拍熟 2~3 岁 |
| 翻译 `<d>` 内的对白 | 逐字保留原语言 | 违反"不翻译不改写" |

## 13. 一页速查（Ref2VA 骨架）

```text
subject_definitions:
<Subject N> is ... in <Picture N>, with ...
<Picture N> is the first frame of [Shot 1], showing ...
<Video N> is the source video for the target video edit.
<Audio N> is the voice-timbre reference for <Subject N> (S1).

summary:
[reference generation] The target video is ...

retention_analysis:
<Subject N> (appears in [Shot 1]): fully_preserved - ...
<Picture N> ([Shot 1] first frame): fully_preserved - ...
<Audio N>: reference - ...

detailed_description:
<风格句，一至两句英文，写在 [Shot 1] 之前>
[Shot 1] <画面、动作、镜头、声音；参考标签在首次出现处落地>
[Shot 2] At 00:05.000, the camera cuts to ... <Subject 1> (S1) says, <d>[Chinese] 原始台词。</d>
[Shot 3] At 00:09.000, ...

overall_soundscape:
<1~4 句英文，环境音 + 物理动作声 + 非语言人声；不重复对白>

non_diegetic_music:
<1~3 句英文写乐器/速度/节奏/动态；无配乐写 N/A>
```

**字段顺序固定**：`subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music`。
**字数参考**：生成类任务 `detailed_description` 通常 **350~500 英文词**；对白密集时优先排满口语时间线，不机械凑字数。**单镜头不自动等于可以写短**。
