# ComfyUI 局部区域截图·放大·补细节工作流调研

> 调研日期:2026-08-10
> 需求:自定义选择一张图片的某个区域截图 → 放大到原图大小 → 补充完整区域细节(区域级高清重绘 / Regional Crop-Upscale-Recraft)
> 范围:官方蓝图、官方模板、Bilibili 工作流大全、RunningHub 工作流、ComfyUI-Docs 官方文档、插件源码 README、网络资料

---

## 一、需求理解

用户诉求拆解为三步:

1. **自定义选择区域截图** —— 需要一个"能截图配置"的节点(数字/bbox/mask/前端拖框任一种)
2. **放大到原图大小** —— 把裁出的区域 upscale 到原图分辨率(区域相对被放大)
3. **补充完整区域细节** —— 对放大的区域做局部重绘 / 细节修复,重建清晰细节

典型应用:脸部/物体特写放大、局部细节增强、局部瑕疵修复、老照片局部修复、海报局部重绘等。技术本质 = **区域裁剪(Crop)+ 放大(Upscale)+ 局部重绘(Inpaint/Detail)**。

---

## 二、能"截图配置"的节点盘点

### 2.1 内置节点(零依赖,本机开箱即用)

| 节点 | 截图配置方式 | 说明 |
|------|-------------|------|
| **ImageCrop** | 数字 `x / y / width / height` | 最基础的区域裁剪,坐标数字手填 |
| **ImageCropV2** | `crop_region`(**BOUNDINGBOX** 类型) | 新版本,bbox 输入,区域越界自动约束 |
| **CropByBBoxes** | `bboxes` + `output_width/output_height` | ⭐ **裁剪并直接 resize 到指定目标尺寸** + `padding` + `keep_aspect`(stretch/pad),天然满足"放大到原图大小" |
| **CropMask** | mask | 按 mask 裁剪图片 |
| **LatentCrop** | 数字 x/y/w/h | latent 空间裁剪 |

> 参考文档:ComfyUI-Docs `built-in-nodes/ImageCrop.mdx`、`ImageCropV2.mdx`、`CropByBBoxes.mdx`、`CropMask.mdx`、`LatentCrop.mdx`、`ImageUpscaleWithModel.mdx`、`ImageScale*.mdx`

### 2.2 社区插件节点(需安装)

| 节点 | 插件 | 截图配置方式 | 用途 |
|------|------|-------------|------|
| **FaceDetailer / DetailerForEach** | **ComfyUI-Impact-Pack** | 检测器(UltralyticsDetector 人脸/物体 / MediaPipe)自动 bbox,或自定义 bbox | ⭐ **一站式"框选→裁剪→latent 放大→重绘→贴回原图"**,最贴近本需求 |
| **ImpactImageCrop** | ComfyUI-Impact-Pack | bbox 输入 | 按检测框裁剪 |
| **easy imageCrop** | **ComfyUI-Easy-Use** | 前端可视化拖拽框选 | 最直观的"截图"体验 |
| **easy imageSplitGrid** | ComfyUI-Easy-Use | 网格行列配置 | 拆九宫格/任意网格,配合分块放大 |
| **LayerUtility: CropByMask V2** | **ComfyUI-LayerStyle** | mask 输入(LoadImage 里画) | 按 mask 裁剪区域 |
| **LayerMask: MaskBoxDetect** | ComfyUI-LayerStyle | mask 输入 | ⭐ 把"画的 mask"转成**区域 bbox**(画哪框哪) |
| **InpaintCrop / CutForInpaint** | **comfyui-inpaint-nodes**(Acly) | mask 输入 | 裁剪待重绘区域,自动处理边缘 |
| **InpaintStitch / BlendInpaint** | comfyui-inpaint-nodes(Acly) | — | ⭐ **重绘后贴回原图(零偏移)**,颜色自适应融合 |

### 2.3 本机已装、可直接用的放大/分块节点

| 节点/插件 | 说明 |
|-----------|------|
| **UltimateSDUpscale**(已装) | 大图**分块 tile** 图生图放大,每块放大+重绘细节,降低显存(节点:`UltimateSDUpscale` / `UltimateSDUpscaleCustomSample` / `...Guider`) |
| **ImageResizeKJ / ImageResizeKJv2**(KJNodes 已装) | 按宽高/比例重采样,区域放大到目标尺寸 |
| 内置 `ImageUpscaleWithModel` + `UpscaleModelLoader` | 加载放大模型放大到目标尺寸(本机 `4xNomos8kDAT` 可用) |

## 三、区域框选方式(4 种,任选其一)

1. **数字/bbox 手填**:内置 `ImageCrop` / `ImageCropV2` / `CropByBBoxes` —— 精确但不直观
2. **画 mask 框选**:`Load Image` 节点自带 mask 画笔 → `LayerUtility: CropByMask` / `InpaintCrop` / `LayerMask: MaskBoxDetect` —— 最符合"自定义选择区域"的直觉
3. **自动检测框选**:UltralyticsDetector(人脸/物体)→ `FaceDetailer` / `DetailerForEach` —— 框选人/物自动完成,无需手画
4. **前端拖拽框选**:`easy imageCrop`(EasyUse)可视化拉框

## 四、主流工作流方案(本地来源实例)

### 方案 A:mask 框选 → 裁剪 → 局部重绘 → 贴回原图(零偏移)

**本地实例**
- **RunningHub `图片处理/Qwen-Eidt-2511+SeedVR2.5零偏移遮罩精细化改图局部重绘图像编辑.json`**(迎风,442 赞 / 9633 次运行)
  - 节点:`InpaintCrop`(按 mask 裁剪)+ `CropWithPadInfo` + `InpaintStitch`(贴回)+ `TextEncodeQwenImageEditPlus` + `FluxKontextMultiReferenceLatentMethod` + `WujiCleaner`/`WujiUpscaler` 精修
  - 模型:`WuJi_Qwen2511-AIO` 聚合版 + `seedvr2_ema_3b-Q4_K_M`(局部重绘后 SeedVR2 精修)
  - ⭐ 最贴合本需求:画 mask 选区域 → 局部重绘 → 零偏移贴回 → SeedVR2 补细节
- **Bilibili `f7d2ce4a-SDXL-局部重绘.json`**
  - 节点:`CutForInpaint` + `BlendInpaint` + `INPAINT_ApplyFooocusInpaint`(Fooocus inpaint)+ `IPAdapter`
  - 模型:`fooocus_inpaint_head.pth` + `MAT_Places512`(matting)+ SDXL inpaint checkpoint
- **Bilibili `1f7d0da7-FLUX-局部重绘.json`**
  - 节点:`InpaintModelConditioning` + `DifferentialDiffusion` + `FluxGuidance` + `easy ipadapter` + `ReduxAdvanced`
  - 模型:`flux1-fill-dev` / `flux1-krea-dev-fp8` / `flux1-redux-dev` + `t5xxl_fp8` + `clip_l` + `ae.sft`

**流程**:`LoadImage`(画 mask)→ mask 裁剪区域 → 局部重绘(KSampler 只重绘 mask 区,或 inpaint 模型)→ `ImageCompositeMasked` / `BlendInpaint` 贴回 → (可选)SeedVR2 精修。

### 方案 B:区域自动放大重绘(Detailer 系,最省事的"截图放大补细节")

**插件**:ComfyUI-Impact-Pack 的 `FaceDetailer` / `DetailerForEach`
**机制**:检测器给出区域 bbox → 裁剪该区域 → **latent 放大到设定倍率(如 2x,即"放大到原图大小")** → KSampler 重绘补细节 → 无缝贴回原图。
**适用**:人脸特写放大增强、物体区域细节补充;配合 SEGS(`MaskToSEGS` + `DetailerForEach`)可对任意 mask 区域操作。
**本地参照**:RunningHub `图片处理/扩图 Flux Outpaint .json`(Epsilon)内已用 `MaskToSEGS` + `DetailerForEach` 做区域精修,可作参考。

### 方案 C:整图分块放大补细节(不手动框选,自动分块)

**本地实例**
- **RunningHub `创意玩法/九宫格拆分放大.json`**
  - 节点:`easy imageSplitGrid`(拆 9 格)+ `UltimateSDUpscale`(每格分块放大重绘)+ `UpscaleModelLoader`
  - 模型:`4x-UltraSharp.pth` + F.1-dev-fp8 + `ae.sft` + `clip_l` + `t5xxl_fp8`
- **RunningHub `图片处理/万物高清放大修复不改变原细节(分块)seedVR2+.json`**(安仔先生666,309 赞 / 28114 次运行,全站第 4)
  - 分块 + SeedVR2 修复,主打"放大不改变原细节"
- **UltimateSDUpscale(本机已装)**:直接拖入即用,大图分块图生图放大,是 8GB 显存放大补细节的首选现成方案。

### 方案 D:高清修复 + 细节增强(整图或局部)

**本地实例**
- **Bilibili `e1ec4613-SUPIR图像高清放大细节修复.json`**:节点 `SUPIR_Upscale` + `DF_Image_scale_to_side`;模型 `SUPIR-v0F_fp16` + `XL写实 LEOSAM HelloWorld v5.0`(SUPIR 为经典超分修复模型,细节重建强,显存需求较高)
- **Bilibili `870bef16-SDXL-精修.json`**:节点 `ImageUpscaleWithModel` + `FluxForwardODESampler`/`FluxReverseODESampler` + `InFlux/OutFluxModelSamplingPred` + `ControlNetApplyAdvanced` + 高低频分离(`Image High Pass Filter`/`ImageBlur`)+ `easy imageColorMatch`;模型 `4x_NMKD-Superscale` + **`Flux.1-dev-Controlnet-Upscaler`**(Flux 放大 ControlNet)+ `苏-FLUX皮肤细节增强LoRA` + `麦橘超然 majicFlux` —— 细节增强一流,但流程复杂、显存高
- **RunningHub `二次元/细节增强_Z-image+I2I+高清修复+去除AI感.json`**:`ImageUpscaleWithModel` + `ImageResizeKJv2` + `VAEEncodeTiled`/`VAEDecodeTiled` + `AILab_QwenVL`(反推 prompt);模型 `z_image_turbo_bf16` + `4xRealWebPhoto_v3_atd` + `qwen_3_4b`
- **RunningHub `二次元/Flux2+Klein控油+高清放大+增强细节.json`**(H5N1,641 赞 / 12316 次运行):FLUX.2 Klein 控油 + 高清放大 + 细节增强(本机已有 `flux-2-klein-9b-fp8`)

### 方案 E:区域检测辅助(把"自定义区域"变成 bbox)

**本地实例**:RunningHub `插件/遮罩区域检测 工作流示例 mask_box_detect_example.json`
- 节点:`LayerMask: MaskBoxDetect` —— 把你手绘的 mask 转成区域 bbox,可接 `CropByBBoxes` / `DetailerForEach` 等
- 思路:在 `Load Image` 里画出想要放大的区域 → 自动得到该区域坐标 → 进入裁剪放大流程

## 五、核心节点用法速查

| 环节 | 节点 | 说明 |
|------|------|------|
| 选区域 | `ImageCrop` / `ImageCropV2` / `CropByBBoxes` / `LayerMask: MaskBoxDetect` / `easy imageCrop` | 数字、bbox、mask、拖框任选 |
| 放大到目标尺寸 | `CropByBBoxes(output_width/output_height)` / `ImageUpscaleWithModel` / `ImageScale` / `ImageResizeKJ` / `LatentUpscale` | 直接指定原图分辨率 |
| 重绘补细节 | KSampler + mask / `InpaintModelConditioning` / Fooocus・LaMa・MAT inpaint 模型 / Qwen-Edit / FLUX.1 fill | 只重绘所选区域 |
| 贴回原图 | `ImageCompositeMasked` / `InpaintStitch(BlendInpaint)` | 零偏移合成,边缘融合 |
| 精修 | SeedVR2 / SUPIR / 4x 放大模型 | 最后一公里清晰化 |

## 六、本机落地建议(8GB VRAM / RTX 4060)

| 优先级 | 方案 | 需安装 | 说明 |
|--------|------|--------|------|
| ⭐ 首选 | **内置节点手动流程** | 零安装 | `ImageCrop`/`CropByBBoxes` 截图 → `ImageUpscaleWithModel`(+`4xNomos8kDAT`)放大到原图尺寸 → Qwen-Edit-2511(`qwen_image_edit_2511_fp8mixed`,本机已有)局部重绘补细节 → `ImageCompositeMasked` 贴回 |
| 推荐 | **Impact Pack `DetailerForEach`/`FaceDetailer`** | 装 Impact-Pack | 自动框选区域→放大 latent→重绘→贴回,一站式,配合 UltralyticsDetector 人脸/物体模型 |
| 推荐 | **comfyui-inpaint-nodes** | 装该插件 | `InpaintCrop`+`InpaintStitch` 零偏移局部重绘,画 mask 即选区域,体验最贴近"截图" |
| 现成 | **UltimateSDUpscale**(已装) | 无需 | 分块放大补细节,8GB 首选现成方案 |
| 可选 | SeedVR2 3B(fp8) | 下载模型 | 局部重绘/放大后的精修提升清晰度 |
| 谨慎 | SUPIR / Flux-Upscaler-ControlNet 精修流 | 下载模型 | 细节最强但显存与流程复杂度高,8GB 建议小图 + 分块 |

> 模型就绪核对:`qwen_image_edit_2511_fp8mixed`✅、`flux-2-klein-9b-fp8`✅、`qwen_image_2512_fp8_e4m3fn`✅、`4xNomos8kDAT`✅;SeedVR2 / SUPIR / 4x-UltraSharp 未就绪。
