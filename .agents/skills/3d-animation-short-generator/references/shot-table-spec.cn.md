# 标准化镜头表规范

## STEP 5：标准化镜头表视频提示词（六列）

角色卡和场景卡锁定后，以镜头信息表的形式输出标准化视频提示词。此步骤为强制步骤，不能与分镜或视频生成互换。创建一个画布表格节点或 Markdown 表格，命名为 `标准镜头信息表` 或 `standard-shot-table`。

表格必须按此顺序恰好包含六列：

| 镜头 ID 与时长 | 连续性交接 | 参考锚点（空间 + 身份） | 钩子类型 | 镜头描述（逐秒指令） | 音频与对白音轨 |
|---|---|---|---|---|---|

列规则：

- **镜头 ID 与时长**：镜头编号加计划时长，例如 `S03 / 6s`。
- **连续性交接**：本镜头如何自然延续前一镜头结束时的画面、道具位置、视线、角色姿态、声音桥或情绪状态，以及它如何铺垫下一镜头的开场。这是跨镜头连续性的主线。
- **参考锚点（空间 + 身份）**：四个子字段，全部必填。
  - `Fixed Landmarks` — 场景卡中的具名地标，及其相对屏幕的位置（例如 `door-frame: right third`、`kitchen-island: center bottom`）。
  - `Character Positions (camera view)` — 镜头中每个角色的相对屏幕位置（左/中/右、上/中/下、前景/中景/背景）、面朝方向以及初始姿势。
  - `Exited Character Status` — 对于上一镜头在场但本镜头不在场的角色，说明其画外位置和原因（例如 `Mia — exited frame-left, last seen holding apple basket at door-frame`）。
  - `Lighting Baseline` — 继承自场景卡的主光/辅光/轮廓光方向，外加每个镜头的修改项（例如 `key: warm overhead, fill: cool bounce right, modifier: window-backlit silhouette`）。
  - 外加身份绑定：精确的已批准角色卡名称和精确的已批准场景卡名称。
- **钩子类型**：取自受控词汇表的一个简短标签，例如 `visual-joke`、`reversal`、`suspense`、`tender`、`chase`、`reveal`、`callback`、`expression-beat`。用于每集钩子分布自检。
- **镜头描述**：景别、摄像机运动、荷兰角设计、表演风格、SFX、负面提示词、**视频模型生成说明**（Step 7 中选择的模型——H3 或 Seedance 2.0——会收到略有不同的提示词形态；对于 H3 强调包装关键词以及文字/UI/动态图形清晰度，对于 Seedance 2.0 强调电影级运镜和弹性表演），以及必填的 `Per-Second Directives` 小节。该小节必须将镜头拆解为逐秒指令，例如 `0–1s`、`1–2s`、`2–3s`；对于亚秒级关键节拍，使用 `2.0–2.5s` 样式的标记。每条逐秒指令必须涵盖全部五项必备元素：
  1. 动作 / 姿势 / 表情（适用时包括挤压与拉伸、预备动作、过冲、后续动作）
  2. 摄像机运动（推 / 拉 / 摇 / 俯仰 / 手持晃动 / 固定 / 环绕）
  3. 空间位置（角色在哪里、手里拿着什么、画面中有哪个地标）
  4. 音频提示（旁白 / 对白 / SFX / 呼吸 / 静默——或出于有意而为则写 `silent`）
  5. 向下一秒或下一镜头的交接（本秒为下一秒锁定了什么状态）
- **音频与对白音轨**：该镜头完整的时间顺序音频脚本，与逐秒提示分开。字段：
  - `Narration` — 带时间范围的画外音文本（无旁白则省略）。
  - `Dialogue` — 台词、说话者、语气、时间范围。
  - `SFX` — 带时间锚定的关键音效。
  - `Performance Note` — 当主角在画外讲述时，标记 `narrator-mouth-closed: true`；描述旁白期间的表情路径；为每句对白描述具体的视线和身体动作变化。

表格全局规则：

- 每个镜头必须通过 `Continuity Handoff` 列自然继承上一镜头的画面状态，并在同一列中为下一镜头做铺垫。
- 每个镜头行必须包含覆盖镜头首帧到末帧整个时长的逐秒指令，包括动作、姿势、表情、摄像机运动、空间位置、声音提示和连续性交接。
- 逐秒指令必须足够具体，以便能直接生成分镜面板；避免诸如"继续移动"这类没有身体、摄像机或道具细节的模糊时间表述。
- 表演必须夸张而有弹性，符合迪士尼式挤压与拉伸、预备动作、过冲、后续动作、交叠、弧线、快速换姿以及清晰的喜剧剪影。
- 景别必须交替使用特写 / 大特写与其他必要的构图方式；避免重复性构图。
- 荷兰角倾斜构图必须设计进追逐、失衡、惊喜或闹剧节拍中。
- 对白语言仅在用户明确要求时使用；否则使用最少的非语言特定反应，或将对白标记为可选 / 待确认。
- 对于含旁白或对白的镜头，角色说话的每一秒都必须记录嘴巴是张开还是闭合；画外讲述者默认闭合，画内对白默认张开。
- 离开画面的角色必须在 `Exited Character Status` 中至少跟踪一个镜头，在明确离场连续两个镜头后将其移除。

然后展示用户选择卡片：

- 批准表格并运行自检（推荐）
- 调整镜头连续性
- 让动画更夸张
- 调整特写 / 大特写节奏
- 调整荷兰角设计

## STEP 5.5：镜头表自检关卡（强制）

在进入铅笔分镜之前，对已批准的镜头表执行硬性自检。如果任何检查未通过，修改表格并重新自检，之后才请用户批准分镜。

六项必检项：

1. **钩子密度**：每个镜头都有 `Hook Type`；每连续三个镜头中至少有一个使用 `reveal`/`reversal`/`callback`；开场镜头和结尾镜头各带一个强钩子（`visual-joke` / `reversal` / `reveal` / `suspense` / `tender`）。
2. **单镜头时长**：任何镜头不超过 15 秒。如果一个节拍需要更长时间，将其拆分。
3. **每镜头角色数量**：任何镜头中的主要角色（定义为有画内动作或对白的角色）不超过三个。
4. **空间锚点继承**：对于每个含两个或更多镜头的室内场景，下一镜头的 `Fixed Landmarks` 和 `Lighting Baseline` 必须与上一镜头一致，或包含一条明确的连续性说明（例如 `door-frame moves from right third to center as camera orbits left`）。
5. **逐秒指令覆盖**：从 `0s` 到镜头时长的每一秒都被一条 `Per-Second Directives` 条目覆盖，且每条条目都包含全部五项必备元素（动作/姿势/表情、摄像机、空间、音频提示、交接）。允许像 `2.0–2.5s` 这样的亚秒级节拍，但不得留下任何时间空隙。
6. **跨镜头连续性**：逐行阅读 `Continuity Handoff` 列可形成连续链条——任何镜头都不能从与上一镜头结束状态相矛盾的状态开始。任何翻转视线、角色位置、道具状态或光照的镜头都必须明确标注翻转（例如 `HARD CUT — time skip: 2h`）。

如果六项全部通过，在画布表格节点顶部盖上 `shot-table self-check: passed` 印记，并展示用户选择卡片：

- 批准自检并绘制镜头分镜（推荐）
- 显示自检详情
- 修订未通过的检查项
- 重新运行自检

如果任何检查未通过，不得进入 Step 6。返回 Step 5，列出未通过的行，并在表格修正且自检通过后，才重新展示分镜批准卡片。
