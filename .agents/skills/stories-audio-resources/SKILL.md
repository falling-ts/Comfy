# 故事库音频与拆解类资源规范

> 「资源 ID 规则」见 `stories/AGENTS.md`；「表格 md 文件规范说明」见技能 `stories-resource-tables`。

### 视频截帧（无数据表）

**2026-10-02 起 `0050_视频截帧.md` 已删除**，这个流程不再有资源表：工作流 `0050_视频截帧` 自带「加载视频」节点（`FallingTSLoadVideo`），在节点下拉里手选 output 里的原视频 → 点「截帧」取帧（可多张）→ 点「完成」把选中帧输出到 首帧/关键帧/尾帧 三个 **`AutoSaveImage`（自动保存节点）**：执行到本节点即落盘、**没有「保存」按钮**，用后缀区分首帧/关键帧/尾帧。

产物文件名 = 加载节点上的 **「序列号」+「名称」**（合成 `<序列号>_<名称>` 作前缀，序列号自动取产物目录里最大编号 + 1）+ 该保存节点自己的后缀，落在 `output/0050_视频截帧/`（如 `00007_书房_首帧.png`）。**不要为它建表，也不要用 `@{...}` 引用它。**

### 视频拆音（无数据表）

**2026-10-02 起 `0051_视频拆音.md` 已删除**：工作流 `0051_视频拆音` 用同一个「加载视频」节点的 `audio` 输出（拆音不需要截帧，不受「完成」门控）→「音频截段」在波形上拖两侧把手选区 → 点「截段」累积（可多段）→ 点「完成」输出 截段 1/2/3 → 三个预览音频。

文件名口径同「视频截帧」：`<序列号>_<名称>` 前缀 + 各自后缀，落 `output/0051_视频拆音/`。**不要为它建表。**

### 截取声音（无数据表）

**2026-10-02 起 `0070_截取声音.md` 已删除**：工作流 `0070_截取声音` 用「加载音频」节点（`FallingTSLoadAudio`，下拉手选 output 里的音频，节点内可直接试听）→「截取音频」波形截段（可多段）→ 每个截段各接一个「截取音频预览」，可试听并点「保存」落盘。
