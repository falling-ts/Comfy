# 文本与铅笔分镜指南

## STEP 6：文本分镜文档（默认）+ 铅笔图像分镜（可选）

Step 5.5 自检通过后，在产出任何分镜产物之前展示分镜模式选择卡片：

- **仅文本分镜文档（默认，推荐）**——一个画布文本节点，包含所有镜头分镜，作为文档内小节。镜像"半旁白剧"分镜结构：逐镜头字段（标题 / 钩子 / 场景 / 角色 / 空间锚点 / 连续性 / 表演）加上皮克斯式逐面板四象限内容，以及可选的 ASCII 版式。以近乎零成本承载全部质量把控信息。Step 7 中选择的视频模型直接以此作为逐镜头渲染参考。
- **文本分镜文档 + 多面板铅笔图像（可视化模式，可选）**——仍然产出文本分镜文档作为权威产物，同时每个镜头额外生成一张多面板铅笔图像供人工审核。成本更高，适合用户希望在投入视频生成前获得视觉预览的场景，或当挤压与拉伸 / 姿势剪影是主要风险、用户想预先做视觉检查的场景。

将所选分镜模式存入 Project Brief，并在 Step 7、Step 9 以及重新生成纪律中复用。

### 默认路径：单一文本分镜文档

生成一个名为 `<title> text storyboards` 的画布文本节点（整部短片使用一个文档）。即使同时产出铅笔图像，此文档也是 Step 7 的权威渲染参考。其结构镜像"半旁白剧"分镜——每个镜头都是同一文档中的一个小节，用户无需切换节点即可阅读跨镜头连续性。

文档顶部信息（文档顶部的头部块）：

- 项目标题、已批准的视频模型、已批准的分辨率、分镜模式以及自检状态（例如 `shot-table self-check: passed at <timestamp>`）。
- 一个简短的目录，列出每个镜头、其钩子及其小节锚点（`S01`、`S02`、……），方便用户跳转。

逐镜头小节结构（每个镜头一个 `##` 标题，按镜头顺序）。每个小节必须按此顺序包含以下字段——直接改编自"半旁白剧"分镜：

1. **镜头标题与时长**——镜头的人类可读短标题，加上 `S<N> / <duration>s`（例如 `S03 / 6s`）。
2. **钩子类型**——受控词汇表之一：`setup` / `visual-joke` / `reversal` / `reveal` / `callback` / `suspense` / `tender` / `chase` / `expression-beat` / `climax`。供每集钩子分布自检使用。
3. **场景与角色**——精确的场景卡名称和精确的画内角色名（绑定到角色卡）。
4. **空间锚点卡**（必填，四个子字段——直接改编自"半旁白剧"）：
   - `Fixed landmarks` — 具名地标及其相对屏幕的位置（例如 `door-frame: right third`、`kitchen-island: center bottom`）。
   - `Character positions (camera view)` — 每个画内角色的相对屏幕位置、面朝方向和初始姿势。
   - `Exited character status` — 上一镜头在画内、本镜头不在场的角色，连同其画外位置和原因。
   - `Lighting baseline` — 继承自场景卡的主光/辅光/轮廓光方向，外加每镜头修改项。
5. **连续性**（镜像"半旁白剧"的交接字段）：
   - `Continuity from S(N-1)` — 一到两句话，引用上一镜头的结束状态。
   - `Continuity to S(N+1)` — 一句话，铺垫下一镜头的开场。
6. **双重绑定**——`[char:角色名-01] [char:角色名-02] ... [scene:场景名] [hook: visual-joke]`——精确的角色卡名称、场景卡名称、钩子类型。这些只是分镜专用参考标记；视频模型在渲染时会将其剥离。
7. **逐面板四象限内容**（每个面板一个块，按时间顺序；这是皮克斯式逐秒指令，从表格行逐字保留）：
   - `Timecode` — 例如 `0–1s`。
   - `Pose + Expression` — 具体的身体姿态、剪影、关键道具握持、视线、面部表情路径；对于弹性节拍，明确标注挤压 / 拉伸 / 预备动作 / 过冲。这是每个面板中最大的小节，也是视频模型读取的视觉节拍。
   - `Camera` — 景别、摄像机运动（推 / 拉 / 摇 / 俯仰 / 手持晃动 / 固定 / 环绕）、适用时的荷兰角说明。
   - `Audio + Anchor` — 音频提示（`♪ narration: ...` / `dialogue: ...` / `SFX: ...` / `silent`）和空间锚点说明（`door-frame: right third` / `Mia: center midground facing camera`）。
   - 表演说明（镜像"半旁白剧"）：对于旁白秒数，标记 `narrator-mouth-closed: true`；对于画内对白，标记 `mouth-open: speaker` 并描述表情路径 / 视线 / 身体动作变化。
8. **版式规则**（逐镜头应用）：
   - 3 秒镜头 → 3 个面板（每秒 1 个）。
   - 4 秒镜头 → 4 个面板。
   - 5 秒镜头 → 5 个面板。
   - 6 秒镜头 → 6 个面板。
   - 7 秒及以上镜头 → 每秒一个面板；对于亚秒级关键节拍，仅当该节拍是该镜头的钩子时，才额外添加一个小型面板，例如 `2.0–2.5s`。
   - 面板必须覆盖从首帧到末帧的完整镜头时长，不留时间空隙。
9. **逐面板绑定**：
   - 绑定表格行中列出的精确角色卡，以锁定外观、面部、发型、身体比例、服装、标志性道具和角色身份。使用与表格相同的角色名。
   - 绑定行中列出的精确场景卡，以保留环境、道具、地标、运动路径和空间逻辑。
10. **可选 ASCII 版式块（强烈推荐，零成本）**：
    - 为每个面板附加一个小型 ASCII 草图（或为整个镜头附加一个组合草图），让用户无需渲染图像即可在数秒内浏览空间版式。示例：
      ```
      [0-1s]  Mia (L, mid)         door-frame (R)
              ──跪下，双手捧着苹果筐──
              cam: 低角度推进，固定
              audio: silent | anchor: basket center-bottom
      [1-2s]  ...
      ```
    - ASCII 块仅供参考；视频模型读取的是上面结构化的 `Per-panel four-quadrant content`，而非 ASCII。
11. **分镜专用标记**：
    - 当节拍关键时，在面板时间码后附加 `[BEAT]`。
    - 当面板必须向下一面板或下一镜头交接特定状态时，附加 `[HANDOFF → ...]` 并加上短标签，例如 `[HANDOFF → S04 opening]`。

逐镜头小节模板（复制粘贴骨架，适用于任何镜头）：

```markdown
## S03 / 6s — 标题: 奶奶把苹果筐递给 Mia

- **钩子类型**: reveal
- **场景与角色**: scene:kitchen | char:Mia, char:Grandma
- **空间锚点卡**:
  - 固定地标: door-frame（右三分之一），kitchen-island（中底部）
  - 角色位置: Mia（左，中景，面向镜头）| Grandma（右，前景，面向 Mia）
  - 离场角色状态: —
  - 光照基线: 暖色顶光主光 + 右侧冷色反射补光
- **自 S02 的连续性**: 奶奶弯下腰从中岛拿起苹果筐
- **到 S04 的连续性**: Mia 接住筐转身，门铃响起
- **双重绑定**: [char:Mia] [char:Grandma] [scene:kitchen] [hook:reveal]

### 逐面板四象限内容

#### 0–1s
- 姿势 + 表情: 奶奶弯腰双手持筐；Mia 左侧站姿，眼神好奇
- 摄像机: 中景固定，平视
- 音频 + 锚点: silent | Mia: 左中景 | basket: 中底部
- 表演: [BEAT]

#### 1–2s
- 姿势 + 表情: 奶奶手臂伸向 Mia，筐倾斜；Mia 双手前伸准备接
- 摄像机: 中景固定，平视
- 音频 + 锚点: ♪ SFX: 竹筐摩擦声 | anchor: door-frame: 右三分之一
- 表演: [HANDOFF → S04 opening]

#### 2–3s
...

### ASCII 版式（可选）
[0-1s]  Grandma (R, fg)        door-frame (R, bg)
        ──举起筐──        Mia (L, mid)
        cam: 固定 | silent
[1-2s]  ...
```

所有小节写完并放置到画布后，直接进入 Step 7。默认模式下不调用任何图像生成模型。

### 镜头级提取（重度迭代模式）

默认的单文档形式针对阅读和跨镜头连续性做了优化。当用户标记某个特定镜头需要重度迭代（通常是高潮 / 追逐 / 闹剧节拍，这些镜头的逐面板内容需要多轮修订）时，将该小节提取为独立文本节点，使迭代局部化：

- 用户信号：在 Step 6 之后的任何时刻，用户说出诸如"let me focus on S05"、"S05 needs rework"、"extract S05"，或在分镜批准选择卡片中选中某个镜头。
- 提取机制：
  1. 创建一个名为 `<title> S05 text storyboard (extracted)` 的新画布文本节点。
  2. 将文档中 `## S05` 小节的完整内容移入新节点。
  3. 在文档中，将 `## S05` 小节替换为一行占位符：`> S05 — extracted to standalone node (see `<title> S05 text storyboard (extracted)`)`。
  4. Step 7 为 S05 读取提取出的节点；其余所有镜头仍从文档读取。
- 重新整合：当用户满意后，将独立节点折回文档（用最新内容替换占位符），并归档独立节点。
- 多个提取镜头：每个镜头各有其独立节点；文档用占位符跟踪它们。

提取机制的存在是因为独立节点应"按需使用而非默认使用"——但当某个特定镜头的迭代压力很高时，它们始终可用。

### 可选路径：多面板铅笔图像分镜（可视化模式）

如果用户在分镜模式选择卡片中选择了可视化模式，则在文本分镜文档之外，每个表格行还要额外生成一张多面板铅笔分镜图。文本分镜文档仍为权威渲染参考；铅笔图像仅供人工审核。

每张铅笔分镜图：

- **双重绑定标签（右上角，图上必填）**：
  - `[char:角色名-01] [char:角色名-02] ...` — 该行使用的精确角色卡名称。
  - `[scene:场景名]` — 精确的场景卡名称。
  - `[shot: S03] [dur: 6s] [hook: visual-joke]` — 镜头 ID、时长和钩子类型。
  - 这些标签只是分镜专用参考标记；视频渲染时会将其剥离。
- 绑定该行列出的精确角色卡，以锁定角色外观、面部、发型、身体比例、服装、标志性道具和角色身份。
- 绑定该行列出的精确场景卡，以保留环境、道具、地标、运动路径和空间逻辑。
- 将该行中每条逐秒指令转换为一个分镜面板或一个清晰标注的节拍面板；对于 4 秒镜头，通常创建 4 个面板；对于 6 秒镜头，通常创建 6 个面板；对于亚秒级关键节拍，仅在需要时额外添加小型面板。
- **面板物理版式（必填）**：
  - 3 秒镜头 → 1×3 横条。
  - 4 秒镜头 → 2×2 网格。
  - 5 秒镜头 → 顶行 3 个 + 底行 2 个。
  - 6 秒镜头 → 2×3 网格。
  - 7 秒及以上镜头 → 3 行，面板均衡排布。
  - 每个面板占据相同的画布面积；不要让某个面板独占。
- **逐面板四象限内容（必填）**：
  - 左上：时间码（例如 `0–1s`）。
  - 右上：姿势 + 表情草图（面积最大；实际的视觉节拍）。
  - 左下：摄像机图标 + 运动箭头（推/拉/摇/环绕/固定）以及荷兰角的简短标注。
  - 右下：音频提示（例如 `♪ narration: "I knew it."` / `SFX: door creak` / `silent`）和锚点说明（例如 `door-frame: right third`）。
- 在同一张单镜头分镜图内按阅读顺序排列面板；不得将多个不同镜头合并到一张图中。
- 每个面板必须标注其时间码，例如 `0–1s`、`1–2s`，并显示对应的姿势、表情、动作、摄像机运动、道具位置、SFX 提示和连续性交接。
- 只输出纯粹的黑白铅笔线稿：无彩色、无最终渲染光照、无精修的 3D 渲染。
- 在分镜图上标注镜头编号，并在有用时为每个面板包含摄像机运动图标 / 标记。
- 在有用时包含分镜专用标记：铅笔构线、动作箭头、摄像机路径图标、时间标记和小备注。
- 将草稿仅作为视频渲染参考素材，而非最终美术。

### 分镜批准（两种模式）

所有文本分镜小节（以及可视化模式下启用时的铅笔图像）产出后，按镜头顺序放置到画布上，并按以下方式分组：
- `<title> text storyboards`（默认模式，单文档），或
- `<title> text storyboards + multi-panel pencil storyboards`（可视化模式，将文本文档和铅笔图像分开分组，因为铅笔图像包含文本文档所没有的双重绑定标签、ASCII 标签和镜头编号）。

展示用户选择卡片：

- 批准分镜并渲染镜头视频（推荐）
- 提取 / 重新整合某个镜头（在文档与独立节点之间移动小节）
- 重绘所选铅笔分镜（可视化模式）
- 修复角色一致性
- 修复场景逻辑
- 修复摄像机标记
- 修复音频/锚点标记

### 分镜生成失败回退（仅可视化模式）

如果无法以所需质量生成铅笔图像分镜（例如版式崩塌、标签难以辨认、面板合并、角色不一致），在询问用户之前按以下顺序升级处理：

1. **第一次重试**：以收紧后的提示词重新生成同一镜头的分镜，提示词中明确提及四象限版式、`[char:…] [scene:…] [shot:…]` 标签以及每个面板的内容规则。
2. **第二次重试**：去掉右下角音频/锚点象限的文字（保留为带有小 `♪` 标记的空白单元格），以减少文字负担；这通常能在不丢失视觉节拍的情况下修复难以辨认的标签。
3. **第三次重试**：减少一个面板数量（例如 6 面板 → 5 面板，通过合并两个最不重要动作的秒数），并将摄像机图标简化为单向箭头。
4. **同一镜头三次尝试失败后**：暂停并向用户展示选择卡片：
   - 仅针对失败镜头切换为色块分镜（用灰色方块表示姿势，无铅笔线条）。
   - 丢弃失败镜头的铅笔图像，该行仅依赖文本分镜文档。
   - 在 Step 5 中将失败镜头拆分为两个更短的镜头，并重新运行 Step 5.5。
   - 手动提供参考图像来绑定，而非生成。

在默认文本模式下，整套回退均无必要——文本分镜只有在模型无法生成连贯的结构化文本时才会失败，此时应返回 Step 5 修改表格行。
