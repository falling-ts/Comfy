# 视频模型选择与提示词塑形

## STEP 7：视频模型选择卡片 + 单镜头视频片段

### 视频模型选择卡片（任何片段渲染前必须展示）

在渲染任何片段之前，展示视频模型选择卡片。选择结果存储在 Project Brief 中，并在本项目的每个片段中复用，除非用户之后更改。

视频模型卡片：

- **H3（推荐默认）**——在视觉包装、动态图形、文字/UI 清晰度、多模态上下文理解以及成本效益（2K 分辨率下约为同类旗舰模型价格的 1/3，768P 下为 1/2）方面表现出色。原生双通道音频。2K 下每片段最长 15s。最适合：具有强烈设计语言、文字叠加、动态图形时刻、包装式转场，以及音频属于交付物一部分的对白驱动节拍的风格化 3D 动画短片。
- **Seedance 2.0（高规格动画表演的回退方案）**——在电影级运镜、复杂镜头、弹性皮克斯式表演以及张力驱动的动作方面表现出色。最适合：追逐戏、闹剧节拍、高潮镜头——这些场景的卖点是动画本身而非包装。
- **逐镜头混合（高级）**——让用户在各行的 `Shot Description` 列中标记 `video_model: H3` 或 `video_model: Seedance2`。当项目同时包含重包装镜头和重表演镜头时使用此方案。未标记行的默认为 H3。

### 分辨率选择卡片（视频模型确定后）

视频模型锁定后，展示分辨率选择卡片：

- 768P（推荐用于 H3 首轮；性价比高）
- 2K（H3 默认质量；成本更高，最终渲染更清晰）
- 1080p（推荐用于 Seedance 2.0）
- 720p（Seedance 2.0 草稿；成本最低）
- 匹配项目 / 自定义分辨率

在首个片段渲染前，用户必须确认分辨率。如果用户后续想要更高细节的特写镜头，可以逐镜头更改分辨率。

### 单镜头片段渲染

对于每一行已批准的表格行，调用所选视频模型生成对应的独立视频片段。每个片段必须精确使用文本分镜文档中匹配的小节（如果该小节已提取为独立节点，则使用提取出的节点，否则使用文档内小节）、角色卡，以及该行的场景卡。

所有视频模型通用的逐镜头规则：

- 将文本分镜文档作为叙事、构图、摄像机运动、动作编排、逐秒节奏和镜头编号的权威逐镜头参考。对于已提取到独立节点的镜头，改读提取出的节点。如果还生成了铅笔图像分镜，仅将其用于人工侧的姿势/剪影预检；不得让分镜覆盖文本分镜。
- 将角色卡作为身份信息的权威来源。
- 将场景卡作为环境信息的权威来源。
- **在视频渲染前剥离所有分镜双重绑定标签**（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`）——这些标签只是分镜专用参考标记，绝不能出现在最终片段中。铅笔图像分镜还带有自己的镜头编号、摄像机图标、箭头和备注，渲染时也必须移除。
- 渲染出的片段必须仅包含干净的、全彩的、皮克斯风格的 3D 动画内容。
- 不得有分镜线稿、手绘草图纹理、标签、字幕（除非用户要求）或水印。
- 保持分辨率选择卡片中批准的屏幕尺寸/宽高比和批准的视频分辨率。

### 模型特定的提示词塑形

文本分镜文档（或该镜头的提取独立节点）同时供两个模型使用，但分镜前后的提示词前缀有所不同：

- **H3 提示词前缀**（默认）：强调包装关键词、设计语言、动作清晰度、相关时的文字/UI 呈现，以及双通道音频意图。H3 在指令遵循方面表现出色，因此逐秒指令几乎可以逐字发送。添加：`Pixar-inspired 3D cartoon rendering, C4D + Octane look, stylized Q-version proportions, warm SSS skin, designed-with-detail hair, strong character design language, clean motion, on-brand color palette`。
- **Seedance 2.0 提示词前缀**（表演回退）：强调电影级运镜语言、弹性挤压与拉伸、预备动作、后续动作、光影戏剧性和镜头选择。添加：`cinematic Pixar-quality 3D animation, elastic squash-and-stretch performance, Disney-style anticipation and overshoot, dramatic key lighting, lens-specific depth of field`。

当用户选择了 `per-shot mixed` 时，应用与该行 `video_model` 字段匹配的前缀。
