# H3 确认图模板

## 核心规则
为合作游戏主菜单生成一张精修的 16:9 横版确认图。图像由两个独立系统构成:
• UI 框架(固定)
• 视觉风格(动态)
UI 框架定义布局、构图、信息层级、交互逻辑、阅读动线、菜单结构和可读性。这些元素必须保持不变。
{visual_style} 仅控制美术外观,包括渲染媒介、材质、色彩语言、光照氛围、环境风格、角色设计、服装语言、UI 材质、图标语言、字体外观、装饰母题和整体氛围。
更换 {visual_style} 应像是在同一套专业设计的游戏菜单上套用不同的美术方向,绝不重新设计界面本身。
如果任何默认描述与 {visual_style} 冲突,优先 {visual_style},同时保留 UI 框架。

---

## 设计目标
创建一张 16:9 横版的高品质商业主机游戏主菜单样机图。图像应兼具精修游戏宣传海报的质感与专业游戏 UI 的清晰度。角色与界面必须自然融合,拥有强烈的视觉层级、出色的可读性、干净的构图和明确的交互焦点。

---

## 整体风格
遵循用户选择的视觉风格:{visual_style}。
所选风格控制渲染媒介、插画风格、材质、调色板语言、环境、角色外观、服装设计、UI 外观、图标语言、字体处理、装饰元素和氛围。
所有视觉元素必须属于统一的美术语言。
同一图像内不得混用互不兼容的视觉风格。
UI 框架、布局、层级、构图和交互逻辑无论风格如何都必须保持一致。

---

## 色彩调色板
从 {visual_style} 推导整个色彩系统。
使用:
• {main_background_color} 作为主要背景色。
• {ui_body_color} 作为 UI 主体颜色。
• {text_color} 作为主要文字颜色。
• {functional_accent_color} 作为交互高亮色。
• 红色仅用于警告、危险或退出操作。
整体调色板限制在五种主色以内。
所有按钮、玩家卡、图标、边框、高亮、装饰元素、字体和视觉效果都必须遵循同一色彩系统。
避免在所选调色板之外引入无关颜色。

## 构图
使用固定的 16:9 横版布局。
将 {character_count} 名可玩角色放置在画面中央作为视觉主体。
UI 环绕角色但不遮挡角色。
将玩家信息卡放置在上方左角。
将主菜单纵向放置在右侧。
沿底部放置一条装饰性横向条带,自然适配 {visual_style}(如缎带、警示条、木板、石板、能量条、卷轴等)。
保持清晰的 Z 形阅读动线:
玩家卡 → 角色 → 菜单 → Continue 按钮。
Continue 按钮必须始终是主要视觉焦点。
保留充足的留白和出色的可读性。

## 背景
生成一个自然源于 {visual_style} 的背景。
背景支撑界面而非与界面争抢视觉。
在所有重要 UI 元素后方保留足够的干净留白。
仅在所选风格合适的部位使用细微纹理、环境细节和装饰母题。
避免过度视觉噪点、密集装饰、厚重污渍、划痕、颜料泼溅或分散注意力的纹理。
整体背景应呈现精修、高端、现代、适合商业游戏菜单的质感。

## 角色风格
所有角色严格遵守 {visual_style}。
所选风格决定:
• 渲染媒介
• 身体比例
• 面部风格化
• 服装语言
• 材质处理
• 光照响应
• 动画风格
• 整体角色品质
只有角色身份锚点与姿势保持固定。面部渲染、眼睛设计、鼻子简化、嘴型、皮肤处理、表情风格和头部比例必须完全按 {visual_style} 重新诠释。
任何默认角色风格都不得覆盖 {visual_style}。
