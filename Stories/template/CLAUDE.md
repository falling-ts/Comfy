## 元素提取

这是元素文件（元素总表）：

```
@元素.md
```

### 提取规范

能够根据大纲和正文分解提取以下元素：人物，场景，物品，动植物以及其它影视作品需要的元素，并对元素进行整理放进表格

表格包含：ID，提示词(TEXT)，宽度(INT)，高度(INT)
ID: 元素唯一标识，必须按照「类型-名称」命名，全局严禁重复，用于后续引用与检索
提示词(TEXT): 对该元素的中文详细描述，用于 AI 绘图，需包含外观特征、材质、姿态、色调、视角、画风等关键信息
宽度(INT): 主图生成的像素宽度，全部元素统一 16:9 用 1664
高度(INT): 主图生成的像素高度，全部元素统一 16:9 用 928

#### 要求

元素 ID 必须按照「类型-名称」进行命名，例如人物陈落写作「人物-陈落」，场景地球书房写作「场景-地球书房」

元素表格内容严禁使用任何 Markdown 格式，加粗、倾斜、代码、链接等一律不允许

生成的元素名称全局严禁重复，ID 作为唯一标识，不同分类下也不允许同名

元素提取文件严禁出现任何标题，全文件仅仅由一个大表格构成

## 表格 md 文件规范说明

所有表格 md 文件的第一列永远是 ID

后续字段完全按照 标题(类型) 定义

(类型) 不填写默认是 (STRING)

(类型) 包含如下内容和说明:

(IMAGE): 对应 ComfyUI 的 IMAGE 输出类型
(VIDEO): 对应 ComfyUI 的 VIDEO 输出类型
(AUDIO): 对应 ComfyUI 的 AUDIO 输出类型
(STRING): 对应 ComfyUI 的 STRING 输出类型
(INT): 对应 ComfyUI 的 INT 输出类型
(FLOAT): 对应 ComfyUI 的 FLOAT 输出类型
(BOOLEAN): 对应 ComfyUI 的 BOOLEAN 输出类型
(TEXT): 对应 ComfyUI 的 STRING 输出类型, 但自定义节点的渲染是多行文本框
