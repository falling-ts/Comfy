## 元素提取

这是元素文件（元素总表）：

```
@元素.md
```

### 提取规范

能够根据大纲和正文分解提取以下元素：人物，场景，物品，动植物以及其它影视作品需要的元素，并对元素进行整理放进表格

表格包含：ID，提示词，宽度，高度

ID: 元素唯一标识，必须按照「类型-名称」命名，全局严禁重复，用于后续引用与检索
提示词: 对该元素的中文详细描述，用于 AI 绘图，需包含外观特征、材质、姿态、色调、视角、画风等关键信息
宽度: 主图生成的像素宽度，人物类 9:16 用 928，场景/物品/植物类 16:9 用 1664
高度: 主图生成的像素高度，人物类 9:16 用 1664，场景/物品/植物类 16:9 用 928

#### 要求

元素 ID 必须按照「类型-名称」进行命名，例如人物陈落写作「人物-陈落」，场景地球书房写作「场景-地球书房」

元素表格内容严禁使用任何 Markdown 格式，加粗、倾斜、代码、链接等一律不允许

生成的元素名称全局严禁重复，ID 作为唯一标识，不同分类下也不允许同名

元素提取文件严禁出现任何标题，全文件仅仅由一个大表格构成
