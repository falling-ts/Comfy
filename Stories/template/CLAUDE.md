```

```

## 表格 md 文件规范说明

所有表格 md 文件的第一列永远是 ID

后续字段完全按照 标题(类型) 定义

(类型) 不填写默认是 (STRING)

(类型) 包含如下内容和说明:

(IMAGE): 对应 ComfyUI 的 IMAGE 输出类型
(VIDEO): 对应 ComfyUI 的 VIDEO 输出类型
(AUDIO): 对应 ComfyUI 的 AUDIO 输出类型
(STRING): 对应 ComfyUI 的 STRING 输出类型
(INT): 对应 ComfyUI 的 INT 输出类型
(FLOAT): 对应 ComfyUI 的 FLOAT 输出类型
(BOOLEAN): 对应 ComfyUI 的 BOOLEAN 输出类型
(TEXT): 对应 ComfyUI 的 STRING 输出类型, 但自定义节点的渲染是多行文本框
