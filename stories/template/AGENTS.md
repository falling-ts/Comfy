### 小说风格

你在写小说时，能够借鉴影视剧本，详细描写清楚所在场景布局，存在的人物，场景物体以及中间发生的事件，能够让读者在脑海中形成画面，如同在脑海中看电影

### 镜头语言

写小说按「景别 → 机位角度 → 运镜 → 光学焦点 → 构图 → 光线色彩 → 时间节奏 → 声音」的顺序组织场景描写，让读者脑中成片。这些术语仅用于脑中构景与描写取舍，不得原样写进小说正文。

景别、机位角度、运镜、光学焦点、构图的具体词汇与分类，详见下文「视频类镜头语言词汇表」（同一套影视镜头体系；术语可原样用于视频提示词，但小说正文严禁出现）。

**光线与色彩**：顺光/侧光/逆光/顶光/底光营造明暗氛围，冷暖色调、饱和度与对比奠定情绪基调
**时间与节奏**：镜头时长控制节奏，长镜头连贯沉浸，短镜头紧张急促；切、叠化、淡入淡出衔接转场
**声音**：环境音、对白、配乐、音效，声画同步或错位制造张力

### 图片提示词书写顺序规范

万物建模、万物变化、场景首帧、场景拉镜、场景推镜 的提示词，除遵循各自类型的专属要求外，还必须严格按照以下顺序书写：

1. **整体图片品质**：描述整图画质、清晰度、精细度、光影氛围、环境背景等整体视觉表现
2. **图片元素万物**：列出画面中出现的所有元素与万物（人物、器物、场景物体、生物、道具、自然景物等）
3. **图片风格要求**：写明整体艺术风格（如CG动漫、水墨国风、写实等）

三段顺序不可颠倒，缺失任一段视为不合格。

### 生图类尺寸规范

生图类资源（万物建模、场景首帧）的宽度/高度统一填写 **16:9 = 1344×768**（高清源图，8G 显卡可跑 Qwen 4 步 Lightning 档）。进图生视频/图生场景时，模型会把首帧自动重采样到视频目标 canvas（如 832×480），无需人为改小；同 16:9 比例下直接等比缩放不裁切。像素保持 16 的倍数（VAE 8×8 下采样对齐）：

- 默认统一 16:9 = 1344×768（严禁 9:16）
- 需要其他比例时，从 H3 合法桶选取（见「视频类尺寸规范」）
- 总像素约 1.03MP（1344×768）；显存紧张可降 16:9 = 832×480（0.4MP）；高清统一走 4x 外部放大 + 分块重绘

### 视频类尺寸规范（MiniMax H3）

视频类资源（文生场景、图生场景、文生视频、图生视频、首尾视频、参考视频）的宽度/高度按 MiniMax H3 官方 canvas 规则填写：

- H3 固定 **24fps**（视频帧率列一律填 24，严禁填 8）；视频秒数按需求填 5~15 秒（官方训练域）
- canvas 硬规则：**短边 ≤ 768**、**面积 ≤ 768×1344（≈1.03MP）**、每轴为 **32 的倍数**；宽度/高度直接决定生成尺寸，超限不会被自动纠正
- 默认统一 16:9 = **832×480**（480p 低显存档，0.4MP，官方原生工作流默认，适配 8G 显卡）
- 显存充足（16G+）可升档 16:9 = **1344×768**（768p 官方主推档，与 turbo 4 步 LoRA 训练域一致）
- 其余比例合法桶：21:9 = 1536×672、3:2 = 1152×768、4:3 = 1024×768、1:1 = 768×768、3:4 = 768×1024、2:3 = 768×1152、9:16 = 768×1344、9:21 = 672×1536
- 低显存/加速档 9:16 = **480×832**
- **严禁使用 1664×928 等生图桶值**：面积 1.54MP 超出 H3 上限约 50%，属分布外，易质量崩坏；2K 需另行二采放大（SeedVR2 / RTX VSR），不在宽度/高度列表达

#### 万物建模 提示词提取规范

画面必须划分为**四块显示区域**：

1. **特写区域**：位于最左侧，为面部或信息集中部位特写。人物取面部，器物取关键部位（如纹路、刻痕、机关、结构细节）
2. **三视图区域**：位于特写右侧，依次为正面视图、侧面视图、背面视图，用于展示完整外观

提示词中必须逐条列出四块区域各自要表现的外观特征（特写部位细节 + 正面/侧面/背面分别可见的形态特征）。

**三视图按对象类型区分**：

- **人物**：右侧为**全身三视图**（正面/侧面/背面全身），标注"最左侧是特写画面，右侧是三个全身三视图"
- **生物/怪物**：右侧为**全身三视图**，标注"最左侧是特写画面，右侧是三个全身三视图"
- **物品**：只有**物品三视图**（正面/侧面/背面展示物品本体），**不要特写区域、不要特写分区**，不得使用"全身三视图"字样，标注"物品三视图，正面/侧面/背面展示完整外观"

**正方形例外**：当宽度与高度相等（正方形尺寸）时，只展示**单一正面画面**，不要三视图、不要特写分区，提示词中写明"正面展示完整图案"。

#### Qwen-Image-Edit 提示写法（图片修改通用）

万物变化走 Qwen-Image-Edit 多图参考编辑，提示词写作要点：

1. **图号引用**：提示词里用 `图1` / `图2` / `图3`（中文工作流通行）或 `Picture 1/2/3`（正规标签）指代各张输入图，三图顺序对应 图1/图2/图3，接错顺序等于指错图
2. **surgical 指令**：指令只描述"改什么"（surgical instruction），别说长篇大论；文字编辑把目标文字用引号括起
3. **底图与参考**：以某张图为底、其余做参考时，目标图接在 图1（image1），参考图接 图2/图3（image2/image3）
4. **负提示词**：原生 Qwen-Image-Edit 负提示词支持有限，留空或单空格即可
5. **不要手写** `<|vision_start|><|image_pad|><|vision_end|>`：节点自动前缀，手写会破坏模板

### 视频类镜头语言词汇表（静态景别 + 动态运动，提示词可直接使用）

#### 静态镜头类别（依据景别）

影视专业教材（如《电影摄影画面创作》）与拍摄脚本中，依据**景别**（被摄主体在画面中所占比例）划分，静态镜头语言存在完整的**九级光谱**，从最宏观到最微观：

**第一层级：环境与空间（侧重「环境」）**

1. **大远景（Extreme Long Shot）**：人物在画面中仅占极小比例（通常小于画框高度的 1/4），甚至几乎看不清。极力弱化人物，强调环境的广袤、历史的厚重或自然的压迫感；固定机位如同一幅静态油画，让观众凝视人类在宏大空间中的渺小
2. **远景（Long Shot）**：人物约占画框高度的 1/2，能看到全身，但环境依然是绝对主体。固定机位下常做「交代性镜头」，展示故事发生的具体大环境（城市、战场），环境内的风吹草动都会被放大，起定场作用
3. **全景（Full Shot）**：人物从头到脚完整纳入画面，同时保留一定的环境背景。人物与环境「平分秋色」，可完整审视全身形体动作（走路姿态、衣着服饰），人物在固定框架内运动产生清晰的舞台感

**第二层级：人物与动作（侧重「肢体」）**

4. **中全景（Medium Full Shot，或称「七分景」「牛仔景」）**：画面下边框卡在人物**膝盖稍上方**。看不到脚，固定镜头强制放大上半身肢体语言；经典西部片用此景别拍拔枪，静态机位聚焦腰腹核心力量的发力瞬间
5. **中景（Medium Shot）**：画面下边框卡在人物**腰部**上下。叙事中最中性的镜头，兼顾手势动作（手部信息）和面部表情，常用于双人对话或摆弄道具（写字、倒水）；固定机位保证演员调度（走位）的准确呈现
6. **中近景（Medium Close-Up，或称「胸景」）**：画面下边框卡在人物**胸部**（约第三颗纽扣处）。静态镜头中最常用、最考验演员的景别——裁掉手部动作，完全靠**眼神和微表情**传递信息，面部的每一丝肌肉抽动都会被捕捉，适合传递暧昧、犹豫或隐忍的情绪

**第三层级：表情与细节（侧重「心理」）**

7. **近景（Close-up）**：画面下边框卡在人物**肩部**，头部占据画面主体。压缩空间感，增强观众与角色间的心理亲密度；静态拍摄制造「凝视」感，让观众觉得在直视角色灵魂
8. **特写（Close Up，狭义特写）**：人物整个**头部**，或某件物品充满大半个画面。固定不动产生强烈的「静止注视」效应，带有「审视」和「强调」的权力感，常用于揭示重要物件（如打开的信封）
9. **大特写（Extreme Close-Up）**：只表现对象的**局部**（一只眼睛、半张嘴唇、扣动扳机的手指、瞳孔的倒影）。画面内几乎没有空间纵深且机位完全静止，视觉张力全部来源于构图和纹理细节；常用于极致的高潮情绪（惊恐到凝固的瞳孔）或关键悬念（炸药倒计时的秒表跳动）

**景别构图变体（画内人物数量微调，仍属上述 9 级框架内）**：

- **单人静态镜头**：聚焦一个人，孤寂感或专注感
- **双人静态镜头**：固定画框内呈现两人互动，通常取「中景」或「中近景」，显示人物间的物理距离（亲疏关系）
- **过肩静态镜头（Over-the-Shoulder Static Shot）**：「中近景」的特殊构图，前景含模糊的后脑和肩膀。固定不动时极强地建立正反打对话中的「对峙空间感」，让观众感觉坐在现场旁观对话

**逻辑澄清**：景别决定「画面里装什么」，静态（固定不动）决定「画面怎么被观看」。9 种景别全部静态时，「时间」成为最核心的变量——同一中景静态停留 2 秒是「客观交代」，停留 10 秒就变成「压抑或审视」。

#### 静态机位角度（拍摄高度与方向，机位不动）

景别之外，静态镜头的机位角度决定「从什么位置看」。机位不动时，角度即全部空间关系：

1. **平视（Eye Level）**：镜头高度与视线齐平，最客观中立，观众与人物平起平坐
2. **俯视（High Angle）**：机位高于被摄主体向下拍。人物显得弱小、被动、被掌控；环境压过人物
3. **仰视（Low Angle）**：机位低于被摄主体向上拍。人物显得高大、威严、有压迫感；天花板/天空入画
4. **顶视（Overhead / Top-Down）**：机位在被摄主体正上方垂直向下拍。纯平面构图，凸显布局与几何（如桌面物品排列、人物在地面的位置关系）
5. **鸟瞰（Bird's Eye）**：极高处的俯瞰，接近地图视角，展现宏大地理与整体空间结构
6. **底视（Worm's Eye）**：贴近地面极低处仰拍，几乎以地面生物视角看世界，强化渺小与仰望

#### 静态构图形式（取景布局，机位不动）

构图画框内的元素如何摆放，决定静态画面的平衡感与视线引导：

1. **对称构图**：画面左右或上下镜像对称，稳定、庄重、仪式感（如宫殿、走廊、正对门框）
2. **中心构图**：主体置于画面正中央，视觉焦点最直接，常配合对称产生压迫或凝视感
3. **三分法构图（Rule of Thirds）**：画面横竖各分三等份，主体或地平线落在交点上，自然、耐看、经典
4. **框架构图（Foreground Framing）**：前景的门框、窗框、拱门、树枝等形成画中画，框住主体，产生偷窥感与空间纵深
5. **引导线构图**：画面中的线条（道路、栏杆、桌沿、光线）把视线引向主体，强化纵深与方向
6. **对角线构图**：主体或线条沿画面对角线排布，产生动感、张力与不稳定感
7. **前景遮挡/层次**：前景虚化或遮挡物体叠在主体之前，制造空间层次与窥视感
8. **留白/负空间**：主体周围大片空白（墙面、天空、水面），孤独感、呼吸感、极简
9. **满框构图**：主体几乎充满整个画面，没有环境余量，压迫、专注、窒息感

#### 静态光学特性（焦点/焦距/景深，机位与镜头不动）

不移动机位、不变化焦距时的光学状态，同样影响画面观感：

1. **浅景深/大光圈虚化**：焦点清晰、前后景虚化（焦外 Bokeh），突出主体，隔离环境（特写、人像常用）
2. **深景深**：从前景到远景全部清晰，适合交代环境全貌与群体关系
3. **长焦压缩（Telephoto Compression）**：长焦镜头下远近物体空间距离被压缩，背景被拉近放大，层次扁平
4. **广角夸张（Wide-Angle Distortion）**：广角镜头边缘畸变、空间纵深夸大，靠近镜头的主体被放大变形
5. **微距（Macro）**：极近距离拍摄微小细节（纹理、水滴、瞳孔、织物），呈现肉眼难见的微观世界
6. **焦点锁定/泛焦（Pan Focus）**：全画面均匀清晰，无主次虚化，纪实、客观、冷淡

#### 静态镜头功能（叙事职能，机位不动）

按镜头在叙事中的任务划分，静态机位同样承担特定职能：

1. **定场镜头（Establishing Shot）**：开场用全景/远景交代地点、时间、环境氛围，建立故事发生地（常为全景级别）
2. **插入镜头（Insert Shot）**：切入画面中某细节的放大（如桌上的纸条、手里的钥匙），强调信息或情绪
3. **切出镜头（Cutaway）**：切离主场景到相关次要画面（如旁观者的反应、窗外的雨），缓冲节奏或补充信息
4. **反应镜头（Reaction Shot）**：静态拍某人的表情/身体反应（多为近景/特写），传递对前情的情绪回应
5. **空镜/静物镜头（Static Object Shot）**：无人物的静物或环境空镜，抒情、留白、象征（对应动态板块的「空镜头」，此处为机位不动版）

#### 动态镜头类别（依据镜头运动）

动态镜头的本质是**打破「摄影机三不动」（机位、光轴、焦距固定）**。按运动发生的物理与逻辑维度，划分为**十大板块**：

**板块一：三维空间中的宏观位移运动（机位整体移动）**

1. **推镜头**：摄影机沿 Z 轴（纵深）向前移动靠近被摄主体。产生逐渐深入、聚焦、紧张或揭示真相的心理效果
2. **拉镜头**：摄影机沿 Z 轴（纵深）向后移动远离被摄主体。产生疏离、释放、展现环境或结局感
3. **移镜头**：摄影机沿 X 轴（左右）或 Y 轴（垂直）平移。产生强烈的动态感和节奏感
4. **跟镜头**：摄影机跟随运动主体同步移动（前后左右跟随），保持主体在画面中的相对位置基本不变，连贯展示其动作与环境的关系
5. **升降镜头**：摄影机在 Y 轴（垂直）方向整体上升或下降。改变视点高度，展现空间纵深感或营造戏剧性（如从上帝视角降至凡人视角）
6. **环绕镜头**：摄影机沿弧形或圆形轨迹围绕被摄主体运动。产生 360 度的环绕审视感，全方位展示主体与环境的关系
7. **穿梭镜头**：摄影机穿越狭窄空间或障碍物（窗户、栏杆、缝隙、人群）拍摄。产生强烈的空间穿透感和速度感，引导视线深入场景
8. **螺旋环绕**：环绕运动叠加升降位移（围绕主体的圆形轨迹 + 持续上升或下降），形成螺旋线运动。产生「天旋地转」般的沉浸纵深，从低处螺旋升至高处可自然揭示全景（如从庭院螺旋升到屋顶）

**板块二：镜头自身的球形转动运动（光轴与角度变化）**

1. **摇镜头（Pan）**：镜头在水平方向（左右）摆动，扫视环境或连接两个物体
2. **俯仰镜头（Tilt）**：镜头在垂直方向（上下）摆动。Tilt Up（仰视）产生崇高、压迫感；Tilt Down（俯视）产生渺小、压抑感
3. **旋转镜头（Roll / Spin）**：镜头围绕光轴（Z 轴）旋转，画面地平线倾斜或翻转。产生眩晕、失重、混乱或不稳定的视觉效果
4. **荷兰角（Dutch Angle / Canted Angle）**：镜头刻意倾斜（Roll 的一种变体），画面水平线不平行于画框。产生不安、紧张、迷幻或世界颠倒感
5. **甩镜头（Whip Pan / Snap Pan）**：极快速的摇镜头（水平甩动），画面产生强烈动态模糊。用于快速转场、制造紧张感或视觉冲击
6. **综合摇镜**：同时进行 Pan 和 Tilt 的复合转动，实现任意方向的镜头弧线扫视

**板块三：概念级缩放运动（光学与数字尺度变化）**

1. **光学变焦推/拉（Zoom In/Out）**：通过改变镜头焦距放大或缩小画面，不改变透视关系，产生空间被压缩或拉伸的独特感受
2. **急推/急拉（Snap Zoom）**：快速变焦推拉，产生强烈的戏剧性强调或揭示效果（常见于香港动作片与昆汀电影）
3. **数字变焦/后期缩放**：数字后期中通过裁剪和放大实现，可自由控制尺度但会损失画质
4. **宇宙缩放（Cosmic Zoom）**：从微观粒子级别连续放大到星系乃至整个宇宙的尺度
5. **量子缩放（Quantum Zoom）**：进入量子领域的微观尺度，从宏观急剧缩小到亚原子级
6. **宏观缩放（Macro Zoom）**：从宏观世界放大到星系乃至宇宙尺度

**板块四：按拍摄速率与时间轴划分的运动**

1. **升格镜头**：以高于正常速率拍摄（如 48fps/96fps），放映时呈现慢动作。强调瞬间、抒发情感、营造梦幻感（含子弹时间的前置拍摄）
2. **降格镜头**：以低于正常速率拍摄（如 12fps），放映时呈现快动作。制造喜剧效果、压缩无聊时间或表现时光流逝
3. **倒放反向运动**：前期正常拍摄、后期时间轴逆向播放，产生违反物理定律的反向动态效果
4. **长镜头/一镜到底（Long Take / Sequence Shot）**：单个镜头长时间连续拍摄（可达数分钟），中间不剪切，完整承载时间流逝与空间连续。产生强烈的沉浸感、纪实感与仪式感，是时间维度的核心镜头（如开场长镜、走廊枪战长镜）
5. **定格镜头（Freeze Frame）**：画面时间在某一瞬间完全凝固（人物/物体静止不动，仅声效或旁白继续）。常用于强调关键瞬间、制造悬念或作为结尾句号
6. **变速镜头（Time Remap / Ramp）**：同一镜头内播放速度主动变化（先慢后快、先快后慢或中间急停），时间重映射。产生节奏操控感（如起跳瞬间变慢、落地后恢复正常速度）
7. **抽帧/步进（Step Printing）**：按间隔抽取中间帧（如每 3 帧取 1 帧），画面呈现不连贯的卡顿动画感。常用于梦境、记忆闪回或粗粝风格化

**板块五：按物理实现手段与支撑设备划分的运动**

1. **手持/肩扛镜头**：画面带不规则的随机晃动，增强真实感、纪录片感或表现角色的紧张不安
2. **斯坦尼康镜头**：穿戴稳定器行走拍摄，平滑流畅地实现推、拉、摇、移、跟、升降的任意组合，不受地形限制
3. **航拍镜头**：搭载于直升机、无人机等飞行器上，建立宏大的地理环境或壮观场面
4. **遥控头/机械臂镜头（Robo Arm）**：按预设程序做高精度、微米级往复运动，常用于特效合成或高精度绿幕拍摄
5. **索道/飞猫镜头（Cable Cam）**：悬挂在双钢缆上由电机驱动超长距离高速滑行（体育赛事全场俯冲），可叠加电动云台旋转
6. **水下遥控运动（ROV）**：搭载于遥控潜水器，深水中慢速悬浮漂移或微距推拉，运动节奏受水流阻力影响
7. **FPV 穿越机运动**：第一人称竞速无人机高速飞行，同时做剧烈的 Roll 轴横滚与翻转，实现「高速穿梭+旋转+位移」的极限复合运动
8. **滑轨微距移动**：机位沿 Z 轴移动仅几毫米，因放大倍率极高，视觉上产生如跨越峡谷般的剧烈空间穿越感
9. **轨道车镜头（Dolly）**：摄影机安装在轨道车上沿直线/曲线滑动（区别于手持推拉），运动平滑、可精确控制速度与距离，是经典的平稳推拉/横移实现方式（如沿轨道从走廊一端匀速滑到另一端）
10. **摇臂镜头（Jib / Crane Arm）**：摄影机挂在可伸缩大臂上做大幅升降 + 弧线摆动，实现「从地面直冲天际」的宏观垂直运动，或大范围弧形环绕（常配合电动云台旋转）
11. **车载镜头（Car Rig / 车拍）**：摄影机固定在行驶的车辆/交通工具上跟拍（吸盘架、前杠架、侧挂架），与被摄主体同速同向运动，产生高速追车戏的贴地速度感（也可反装拍车内对谈）

**板块六：基于光学物理特性变化的被动/隐性运动**

1. **变宽畸变动态（Anamorphic Breathing）**：变形宽银幕镜头跟焦时，镜片组内部移动导致画面水平拉伸比产生微小瞬时波动，「画面在呼吸」的被动光学动态
2. **焦点呼吸动态（Focus Breathing）**：跟焦过程中镜片组前后位移，画面产生极其细微的「视觉缩放感」（区别于变焦，范围极小，老式镜头尤其明显）
3. **偏振/滤镜动态旋转**：拍摄中电机旋转镜头前的偏振镜或渐变滤镜，动态改变天空颜色、水面反光或画面饱和度

**板块七：虚拟制作与后期特效产生的运动（现场物理机位可能不动）**

1. **虚拟制片联动运动（LED Volume Sync）**：摄影机物理位移时，实时渲染引擎反向移动 LED 背景墙上的虚拟场景贴图，实现物理位移与概念缩放的实时无缝组合
2. **时间切片/子弹时间阵列运动**：一圈环绕的静态相机按顺序逐帧触发，剪辑成连续的环绕动态（摄影机本身未动，靠多静止机位时序接力创造动态）
3. **动态遮罩移位/2.5D 视差运动**：后期将前后景分离，数字缩放分别移动不同图层，制造伪推拉或伪摇移的视差动态

**板块八：按特殊叙事视角与功能划分的运动**

1. **主观镜头（POV）**：模拟故事中角色的视角进行运动（行走、奔跑或倒下的视线）
2. **客观镜头**：以旁观者视角拍摄，摄影机不参与叙事，是绝大多数镜头的默认叙述方式
3. **空镜头**：画面中不出现人物，只拍摄景物或环境，常用于抒情或转场
4. **悬空/顶拍镜头**：摄影机从高空垂直向下拍摄，营造超脱、审视或宿命感
5. **主观环绕（POV Orbit）**：以角色第一人称视角做环绕/转身运动（如角色原地转圈张望、回头扫视身后），把 POV 的代入感与环绕的空间揭示结合，观众直接看到角色「看到的世界」

**板块九：画面内参考系的隐性运动（机位静/动相对论）**

1. **主动摇拍**：摄影机摇动，目标静止
2. **被动摇拍**：摄影机静止，依靠目标极速入画或出画（如火车高速驶过镜头前）产生画面视觉冲刷感，机位不动但视觉上属于动态构图剧变

**板块十：综合经典组合运动镜头**

1. **推拉摇移跟升降的任意复合**：如先摇镜扫视环境，再跟主体，最后推至面部特写，一个镜头完成复杂叙事
2. **滑动变焦**：摄影机物理推/拉 + 光学焦距反向变焦，背景压缩或拉伸，产生空间扭曲的眩晕感（希区柯克变焦）
3. **摇-升降-变焦组合**：水平摇动同时垂直俯仰并叠加变焦，锁定在三维空间中做复杂曲线运动的主体
4. **斯坦尼康长镜头**：穿戴设备行走，同时实现推、拉、摇、移、跟、升降的无缝平滑衔接
5. **跟拍-揭示镜头**：先跟拍主体，当其移开后，通过摇/移揭示出之前被遮挡的关键信息
6. **推+摇组合**：沿 Z 轴推进的同时水平摇动，保持主体在画面中心，产生极强的包围感
7. **移+升降组合**：水平横移的同时垂直升降，营造复杂的空间穿梭纵深感
8. **环绕+变焦组合**：环绕主体旋转的同时进行光学缩放，视觉冲击力极强
9. **宇宙缩放组合**：物理拉镜头 + 光学 Zoom Out + 后期特效缩放，实现从人物拉到星系的全程尺度跨越
10. **量子穿梭组合**：物理推镜头 + 光学 Zoom In + 后期特效穿越，实现进入微观世界的沉浸感

#### 剪辑衔接类别（镜头与镜头的连接）

镜头之间的衔接方式本身也构成视觉语言，提示词中可用以描述转场与节奏：

1. **跳切（Jump Cut）**：同一机位、同一主体间直接硬切，画面主体位置/姿态突变，产生时间跳跃感或急促不安的节奏（新浪潮标志手法）
2. **匹配剪辑（Match Cut）**：前后镜头在构图、形状、动作或声音上相似/呼应的衔接（如从圆形钟表切到圆形月亮），产生隐喻与视觉流动
3. **叠化（Cross-Dissolve）**：前一镜头逐渐淡出与后一镜头叠加过渡，柔和的时空流逝感，常用于时间跳跃或回忆
4. **淡入淡出（Fade In / Fade Out）**：画面从黑场淡入或淡出至黑场，段落的开始与结束，强烈的叙事分隔
5. **划变（Wipe）**：一条分界线扫过画面完成切换（横向/纵向/圆形），风格化、年代感或空间并置
6. **甩切（Whip Cut）**：快速甩镜产生的动态模糊直接衔接下一镜头，动势连贯，节奏凌厉

**动态镜头终极汇总逻辑总表**：

| :--- | :--- |

| **球面转动（旋转轴）** | 摇（Pan）、俯仰（Tilt）、旋转/荷兰角（Roll）、甩镜、综合摇、主观环绕 |
| **微观位移（毫米级）** | 滑轨微距移动、机械臂高精度定位、焦点引起的镜头组补偿位移 |
| **光学内部运动** | 光学变焦、变宽呼吸、焦点呼吸、滤镜旋转渐变 |

### 文生场景

即利用文生视频获取具体描述的场景360度视频，包含ID，场景提示词(TEXT)，宽度(INT)，高度(INT)，视频帧率(INT)，视频秒数(INT)

#### 文生场景 提示词提取规范

场景提示词按 **T2VA** 规范书写，直接以三个核心字段开头，无图像对齐指令：

1. **integrated_multimodal_description**：沿时间线描述场景的视觉风格、初始构图、空间布局与镜头运动，交代前后左右上下的空间方位、环境、光线与氛围
2. **overall_soundscape**：概括整个视频中的环境音与物理动作声
3. **non_diegetic_music**：描述角色听不到、仅观众能听到的背景音乐

### 图生场景

#### 图生场景 提示词提取规范

1. 第一行对齐指令：`对于目标视频，在目标视频的 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完整引用。`
2. 空一行后写三个核心字段：integrated_multimodal_description、overall_soundscape、non_diegetic_music

integrated_multimodal_description 先在图像中确立场景风格、主体、构图与空间锚点，再从首帧向四周展开完整 360 度视角旋转，保持角色、物体与空间关系一致。

### 参考场景

即通过最高9张图片，3个视频，3个音频参考生场景360度视频，包含ID，<Picture 1>(IMAGE)，<Picture 2>(IMAGE)，<Picture 3>(IMAGE)，<Picture 4>(IMAGE)，<Picture 5>(IMAGE)，<Picture 6>(IMAGE)，<Picture 7>(IMAGE)，<Picture 8>(IMAGE)，<Picture 9>(IMAGE)，<Video 1>(VIDEO)，<Video 2>(VIDEO)，<Video 3>(VIDEO)，<Audio 1>(AUDIO)，<Audio 2>(AUDIO)，<Audio 3>(AUDIO)，场景提示词(TEXT)，宽度(INT)，高度(INT)，视频帧率(INT)，视频秒数(INT)

#### 参考场景 提示词提取规范

场景提示词按 **Ref2VA 全参考模式** 规范书写，包含六部分，顺序固定：

1. **subject_definitions**：定义被参考内容及其参考标签，使用 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 四类标签。`<Subject N>` 用于可复用内容（场景、地形、环境、建筑、道具、风格），`<Picture N>` 用于充当帧锚点的图片，`<Video N>` 用于剪辑、续写或参考节奏的源视频，`<Audio N>` 用于被复制或引用的音频
2. **summary**：以 `[任务类型]` 前缀开头（如 `[reference generation]`、`[video continuation]`、`[audio reuse]`），概括目标场景与主要参考关系
3. **retention_analysis**：逐项描述被参考内容如何保留、转移或复用。可见内容用 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`，音频用 `fully_copy` / `partially_copy` / `reference` / `weak_reference`
4. **detailed_description**：按播放顺序逐镜头描述场景画面、运镜、空间布局与声音，在首帧、尾帧、分镜等作用位置插入参考标签
5. **overall_soundscape**：概括环境氛围声与物理音效
6. **non_diegetic_music**：描述仅观众可闻的背景音乐

参考标签一旦赋予某段内容，在全部六部分中始终表示同一含义，不得换义或遗漏。**detailed_description 中必须持续使用参考标签，不得换成纯文字指代**：首次出现时写「标签 + 完整特征描述」落地到具体画面，后续镜头继续使用同一标签（无需重复定义），可配简略文字。标签是模型将画面内容与具体参考素材绑定的锚点，纯文字无法确定对应关系，尤其在多参考（≤9 图 + 3 视频 + 3 音频）时易串。

**Subject 三层绑定机制**：

1. **subject_definitions 登记**：文字描述内容并编号，建立「`<Subject N>` = 某内容」的映射关系
2. **detailed_description 首次出现落地**：写「标签 + 完整特征描述」，把编号真正绑定到具体画面特征。这一步是模型建立编号与画面对应关系的关键，只写编号不写特征会导致绑定变弱
3. **后续镜头纯引用**：直接使用同一标签引用即可，无需重复描述，可配简略文字

**图片编号按输入顺序、内容定位靠文字**：`<Picture N>` 按参考图输入顺序编号（images → videos → audio 各类型独立编号），与画面内位置无关；一张图内多个元素归属哪个 Subject 必须用文字点名（必要时用方位词辅助），模型不会自动按画面左右分配。

场景类公共要求（见上节）在本类型中落实于 detailed_description。

详细规则遵循 H3 全参考模式改写格式指南。

### OrbitSheets场景

#### OrbitSheets场景 提示词提取规范

- **原场景**：锚点图，引用已有的场景图(`@{场景首帧-...}` / `@{场景拉镜-...}` / `@{场景旋镜-...}` 等)，作为 H3 运镜的第一帧
- **场景描述**：location_description，用简洁文字交代场景的空间大小、布局、主要物件与方位关系（供 OrbitSheetsLocationPrompt 生成多视角镜头提示词）

- 空间类型(interior/exterior)、覆盖方式(cut views/continuous move)、旋转(auto/quarter/half/full)、宽景/细节开关为工作流内固定下拉（默认 interior / cut views / auto / True / True），按需在节点上改，不必进表
- 输出：场景视频(`{ID}.mp4`) + 参考板网格图(`{ID}.png`)；选帧默认 shots=6 按内容聚类、count=6、CLIP 图内判定

### Skythread场景

即按 Skythread 三参考法(角色/道具/空场景各一张、职责单一)用 H3 Ref2VA 生成场景视频。包含ID，<Picture 1>角色/主体(IMAGE)，<Picture 2>道具(IMAGE)，<Picture 3>空场景(IMAGE)，视频提示词(TEXT)，宽度(INT)，高度(INT)，视频帧率(INT)，视频秒数(INT)

#### Skythread场景 提示词提取规范

视频提示词按 Skythread 风格书写（非六段式 Ref2VA，而是 I2VA 风味的 R2V 提示）：

1. **三行 `<Picture N>` 定义**：每张图声明为某一内容的「唯一权威」（身份/道具/空场景），并写明保留特征与「不使用此参考中的任何背景」，三者材质与空间相互独立
