### 图片提示词书写顺序规范

万物建模、万物变化、场景首帧、场景拉镜、场景推镜、场景旋镜 的提示词，除遵循各自类型的专属要求外，还必须严格按照以下顺序书写：

1. **整体图片品质**：描述整图画质、清晰度、精细度、光影氛围、环境背景等整体视觉表现
2. **图片元素万物**：列出画面中出现的所有元素与万物（人物、器物、场景物体、生物、道具、自然景物等）
3. **图片风格要求**：写明整体艺术风格（如CG动漫、水墨国风、写实等）

三段顺序不可颠倒，缺失任一段视为不合格。

### 万物建模

即文生图并优化图片，包含ID，提示词(TEXT)，宽度(INT)，高度(INT)，优化提示词(TEXT)

#### 万物建模 提示词提取规范

画面必须划分为**四块显示区域**：

1. **特写区域**：位于最左侧，为面部或信息集中部位特写。人物取面部，器物取关键部位（如纹路、刻痕、机关、结构细节）
2. **三视图区域**：位于特写右侧，依次为正面视图、侧面视图、背面视图，用于展示完整外观

提示词中必须逐条列出四块区域各自要表现的外观特征（特写部位细节 + 正面/侧面/背面分别可见的形态特征），并标注"最左侧是特写画面，右侧是三个全身三视图"。

```
@1000-万物建模.md
```

### 万物变化

即图片换样式并优化图片，包含ID，原建模(IMAGE)，变化提示词(TEXT)，优化提示词(TEXT)

#### 万物变化 提示词提取规范

变化以原建模为底，必须**保留画面构图**：

1. **构图不变**：保持原建模的四块显示区域布局（最左侧特写区域 + 右侧正面/侧面/背面三视图区域）与整体画面构图
2. **特写修改**：对最左侧特写区域进行风格化修改，按需求改变其材质、纹路、配色、氛围等外观表现
3. **三视图统一一致**：右侧三块三视图必须与新特写风格完全统一，同一角色或器物在正面、侧面、背面的外观特征一致，不得出现相互矛盾或风格割裂

提示词中必须写明"保持原构图不变"，逐条描述特写区域的新外观，并强调三视图与新特写保持统一一致。

```
@1010-万物变化.md
```

### 首尾视频

即通过首尾帧和秒数以及提示词生成视频，包含ID，<Picture 1>(IMAGE)，<Picture 2>(IMAGE)，视频提示词(TEXT)，宽度(INT)，高度(INT)，视频帧率(INT)，视频秒数(INT)

#### 首尾视频 提示词提取规范

视频提示词按 **FL2VA** 规范书写，首帧为开场、尾帧为结局：

1. 第一行对齐指令：`参考图片与目标视频的对齐方式 — Picture 1（来自 Shot 1）对齐目标视频的 0.00 秒位置；Picture 2（来自 Shot N）对齐目标视频的 S.SS 秒位置。`
2. 空一行后写三个核心字段：integrated_multimodal_description、overall_soundscape、non_diegetic_music

integrated_multimodal_description 采用「首帧状态 → 可观察的中间变化 → 差异逐渐收窄 → 末帧状态」结构，聚焦主体如何运动、姿势如何变化、物体如何被操控、构图如何演变、场景或光照如何过渡。一般倾向单个镜头，由首帧连续插值到尾帧。

**图片标签使用**：首帧图用 `Picture 1`、尾帧图用 `Picture 2` 引用（对齐指令中即为 Picture 1 / Picture 2）。此模式**不使用 `<Subject N>`**（仅 Ref2VA 全参考模式使用），画面一致性通过 integrated_multimodal_description 中「由 Picture 1 确立的姿势/构图…落定到 Picture 2 确立的姿势/构图」之类的文字描述维持。

### 参考视频

即通过最高9张图片，3个视频，3个音频参考生视频，包含ID，<Picture 1>(IMAGE)，<Picture 2>(IMAGE)，<Picture 3>(IMAGE)，<Picture 4>(IMAGE)，<Picture 5>(IMAGE)，<Picture 6>(IMAGE)，<Picture 7>(IMAGE)，<Picture 8>(IMAGE)，<Picture 9>(IMAGE)，<Video 1>(VIDEO)，<Video 2>(VIDEO)，<Video 3>(VIDEO)，<Audio 1>(AUDIO)，<Audio 2>(AUDIO)，<Audio 3>(AUDIO)，视频提示词(TEXT)，宽度(INT)，高度(INT)，视频帧率(INT)，视频秒数(INT)

#### 参考视频 提示词提取规范

视频提示词按 **Ref2VA 全参考模式** 规范书写，包含六部分，顺序固定：

1. **subject_definitions**：定义被参考内容及其参考标签，使用 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 四类标签。`<Subject N>` 用于可复用内容（人物、器物、场景、服装、动作、风格），`<Picture N>` 用于充当帧锚点的图片，`<Video N>` 用于剪辑、续写或参考节奏的源视频，`<Audio N>` 用于被复制或引用的音频
2. **summary**：以 `[任务类型]` 前缀开头（如 `[reference generation]`、`[video continuation]`、`[audio reuse]`），概括目标视频与主要参考关系
3. **retention_analysis**：逐项描述被参考内容如何保留、转移或复用。可见内容用 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`，音频用 `fully_copy` / `partially_copy` / `reference` / `weak_reference`
4. **detailed_description**：按播放顺序逐镜头描述画面、动作、镜头、声音与对话，在首帧、尾帧、分镜等作用位置插入参考标签
5. **overall_soundscape**：概括环境氛围声与物理音效
6. **non_diegetic_music**：描述仅观众可闻的背景音乐

参考标签一旦赋予某段内容，在全部六部分中始终表示同一含义，不得换义或遗漏。**detailed_description 中必须持续使用参考标签，不得换成纯文字指代**：首次出现时写「标签 + 完整特征描述」落地到具体画面，后续镜头继续使用同一标签（无需重复定义），可配简略文字。标签是模型将画面内容与具体参考素材绑定的锚点，纯文字无法确定对应关系，尤其在多参考（≤9 图 + 3 视频 + 3 音频）时易串。

**Subject 三层绑定机制**：

1. **subject_definitions 登记**：文字描述内容并编号，建立「`<Subject N>` = 某内容」的映射关系
2. **detailed_description 首次出现落地**：写「标签 + 完整特征描述」，把编号真正绑定到具体画面特征。这一步是模型建立编号与画面对应关系的关键，只写编号不写特征会导致绑定变弱
3. **后续镜头纯引用**：直接使用同一标签引用即可，无需重复描述，可配简略文字

**图片编号按输入顺序、内容定位靠文字**：`<Picture N>` 按参考图输入顺序编号（images → videos → audio 各类型独立编号），与画面内位置无关；一张图内多个元素归属哪个 Subject 必须用文字点名（必要时用方位词辅助），模型不会自动按画面左右分配。

详细规则遵循 H3 全参考模式改写格式指南。
